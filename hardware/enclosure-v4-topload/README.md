# Discora V4 · 顶部进碟与中央双喇叭

保留 V4 的折面斜肩、长圆提手和内凹音量旋钮，下半部恢复中央圆形喇叭格栅。两只矩形喇叭在同一块圆格栅后左右并排，均朝正面；左右侧面改为内凹胶囊饰片和周边开放导音通道。CD 入口仍在提手后方的顶部斜面，小状态屏移到顶部前斜面，位于播放键与音量旋钮之间；正面仅保留圆形喇叭格栅。整机 **宽 160 × 深 78 × 高 236 mm**，含脚垫和提手。

## 编辑与验证

在 FreeCAD 中执行 [build.FCMacro](build.FCMacro)，选择目录生成模型。`SPEAKER_CENTER_X/Z` 控制前向双喇叭中心，`PORT_CENTER_Y/Z` 控制侧孔中心，`FRONT_GRILLE_RADIUS` 控制圆格栅；改变这些参数需联动检查前障板、后腔和开孔。`DISPLAY_DECK_Y` 控制小屏在斜面上的前后位置；显示组件共用斜面安装坐标，开窗长宽按斜面内尺寸计。前壳仍保留草图、拉伸、圆角和布尔开孔特征。

`StatusArt` 是曲目、播放、电量和音量的显示内容示意，不是打印件，也不代表固件已经实现界面。`Driver`、`Drive`、板卡和电池均为硬件包络，不能作为采购件制造模型。

FreeCAD 1.1.4 重新打开保存文件后，共 42 个成品对象实体有效；全部成品按包围盒筛选并计算两两相交体积，未检出超过 0.001 mm³ 的重叠。Ø120 × 1.2 光盘的竖直运动包络无碰撞。原正面屏幕开口已封闭，斜面新开窗与显示组件方向一致。左右前喇叭与安装框中心一致、位置对称；左右后腔各有一条半径 0.4 mm 的连续检查通路从喇叭后部到侧面外部，无实体阻挡。该通路只证明几何连通，不证明有效通风面积、调谐频率或声学表现。结果见 [validation.json](validation.json)。

当前仍为外形和空间布局阶段。喇叭尺寸与标称功率已另行记录，但确切型号、实物安装尺寸及声学参数仍待核对；腔体容积与侧孔调谐、气密连接、振膜活动空间、PLA 打印分件、提手强度、紧固件、屏幕实物、走线，以及 UJ-898 在此姿态下的进退碟，均需后续细化与实测。
