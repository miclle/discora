## 供应商资料与待确认项

- 模块结构图标注 SH1106、128 × 64、IIC，PCB 35.4 × 33.5 mm，显示区域 29.42 × 14.7 mm；这些是图纸值，不是实测尺寸。
- 模块规格书第 6 页标注 SH1106，第 24 页注意事项却出现 SSD1306；商品规格图还提到可向客服选择 SSD1306。不能把不同型号的命令和初始化序列混用，最终以所选 SKU、实物及显示测试确认。
- 模块图示排针顺序为 VCC、GND、SCL、SDA；商品图另说明可提供 GND、VCC 顺序的版本，接线前须看实物丝印。
- 商品接口表将 SCL、SDA 写成 SPI 信号，与模块 IIC 标注不一致；不能据此改接为 SPI。
- 模块结构图标注 3.3 V，商品图写 3.3–5 V；板级稳压、上拉电源和信号电平均待确认，商品供电范围不等于 ESP32-S3 GPIO 可承受的电压。
- 图片中的地址标注、实际地址选择及固件使用的地址表示方式，留待接入时核对；2026-11-04 已规划 GPIO10 为 SDA、GPIO11 为 SCL，尚未实现显示驱动或记录实物通信成功。

## Discora 接线规划

2026-11-04：规划 ESP32-S3 **3V3 → VCC、GND → GND、GPIO11 → SCL、GPIO10 → SDA**。GPIO10／11 已在主控供应商图纸引出，未占用当前音频与按键引脚；这只是 `planned` 接线，当前固件没有显示驱动。

上电前确认模块支持 3.3V、实物 VCC/GND 顺序、板载上拉连接到 3.3V，以及主控供电余量。SDA/SCL 不得上拉到 5V，不能从 DAC 的 A3V3 给屏幕供电。控制器、实际地址和显示效果仍待核对。逐线说明及唯一展示的整机接线图见 [整机文档](../../docs/wiring.md#13-英寸-oled-四线接线planned)。
