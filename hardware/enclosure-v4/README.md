# Discora V4 · FreeCAD 外观与布局模型

打开 [Discora-V4.FCStd](Discora-V4.FCStd) 即可旋转、剖切和测量。模型树分为外壳、屏幕与操控、内部支架、硬件占位四组。在树中选中前两组并按空格，可查看内部装配。图片来自同一份 CAD 几何：[整机](preview.png) · [移开前壳与部分零件后的布局](layout.png)。

前壳从圆形点阵窗口延伸到斜肩和横向长圆提手。两只长方形喇叭各朝一侧，胶囊形罩面带真实通孔。UJ-898 立在显示面后方，光盘平面为 XZ，沿 +X 向右退碟。板卡位于后侧，电池靠底。点阵图案仅用于外观评审。

## 修改与验证

光驱毛坯和关键板卡、电池、喇叭都是独立对象。前壳保有截面草图、拉伸、圆角和开孔特征。需要同步调整光驱托轨、喇叭安装框或电池座时，可修改 [build.FCMacro](build.FCMacro) 顶部的 DRIVE、SPEAKER 或 BATTERY，在 FreeCAD 的“宏 → 执行宏”中运行并选择新输出目录。宏会生成一份新的装配文档。改变整机尺寸或部件位置时，也需联动检查外壳轮廓、内部支架和开口。

FreeCAD 1.1.4 重新打开交付文件后，对四组共 37 个成品对象执行了实体有效性检查。排除装饰用亮暗像素之后，对其余成品按包围盒筛选并计算两两相交体积，未发现超过 0.001 mm³ 的重叠。沿 +X 用覆盖 Ø120 × 1.2 碟片运动的实体包络检查光驱内部至右侧出壳路径，未检出几何碰撞。

当前可评审外形、装配方向和空间分配。PLA 试打印、固定件与走线细化、提手承载、喇叭声学表现，以及 UJ-898 在该姿态的实际进退碟，均待后续验证。
