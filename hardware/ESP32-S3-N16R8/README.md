## Discora 使用的接口

方位以元件面朝向观察者、天线在上、USB 口在下为准；背面视图左右相反。

| 接口或资源 | 图纸连接 / 当前用途 |
| --- | --- |
| COM / USB1 | 图纸经 CH343P 接 UART0 GPIO43/44；Discora 用作电脑烧录及日志口 |
| USB / USB2 | D− 接 GPIO19，D+ 接 GPIO20；Discora 用作原生 USB Host |
| USB-OTG | 0 Ω 支路与 D2 并联，连接 USB2 VBUS 与板上 5V；**不是 GPIO3 接地选项** |
| USB-JTAG | 另一条 GPIO3 配置支路，经 R11 10 kΩ 接 VDD33 |
| IN-OUT | 与排针 5Vin 支路 D3 并联；与 USB-OTG 为不同支路 |
| GPIO4 / 5 / 6 | 当前 I²S 诊断的候选 BCLK / LRCK / DATA；可配置，尚未完成 DAC 接线验收 |
| GPIO35 / 36 / 37 | N16R8 八线 PSRAM 资源，不能因图纸引到排针便用于外设 |
| GPIO0 / 3 / 45 / 46 | 启动绑带，保留；GPIO48 为板载 RGB，GPIO39–42 涉及 JTAG |

完整排针顺序见结构化摘录和原理图。供应商毫米图的底板标称长宽为 57.15 × 27.94 mm，含图示天线总长 63.39 mm，两排针中心距 25.40 mm，22 针首末间距 53.34 mm。它们不是当前实验板的实测包络。

旧索引误将 USB-OTG 归入 GPIO3 接地配置，本次已按原理图纠正。供电桥接会改变隔离路径；实际接线和已测边界以 [组装说明](../../docs/assembly.md)、[首次上板记录](../../docs/records/2026-10-31-m1-first-boot.md) 和 [空 Hub 记录](../../docs/records/2026-10-31-m1-empty-hub.md) 为准。音频接线见 [DAC 输出准备](../../docs/audio-output.md)，工程进度见 [当前状态](../../docs/status.md)。

## GPIO7 退盘输入

Discora 0.9.0 默认查询/播放器使用 GPIO7（图纸 J1-7）作为内部上拉输入，常开轻触按键接到 GND。它与 GPIO4/5/6 音频默认值不冲突；基本按键触发及实际退盘已获用户成功反馈；板卡逐网、电气测量及其余场景未验收。见[接线与配置](../../docs/eject-button.md)。
