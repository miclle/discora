# Discora — 需求与验收标准

## 项目定位

以 ESP32-S3 为主控，通过 USB Host 控制标准光驱，实现不依赖 PC/Linux 的独立低成本 CD 播放器；研究进一步的 CD-R/CD-RW 刻录能力。

## 必须满足的约束

- 首版 MCU：ESP32-S3，首测光驱：MATSHITA DVD-R UJ-898 + SATA-USB 桥接器。
- 音乐 CD-DA：44.1 kHz、16-bit、**左右独立双声道**；不得错误混为单声道。
- 首版优先通过 I²S 外接立体声 DAC 输出线路级音频。
- USB 光驱供电与 MCU 控制/数据分开评估；光驱启动或进出盘时不能让主控反复掉电。
- 固件不依赖树莓派、Linux、外部服务器或手机；PC 仅用于调试、刷机和预验证。
- 记录对不同光驱、USB 桥接器和介质的兼容性，不因某一组合成功而推断普遍兼容。
- 设备应可复现地从空白开发板刷入并启动。

## 分阶段功能与验收

### M0：USB 桥接与供电事实确认

- 确认 UJ-898 能被 Linux 识别（实验辅助）。
- 查询识别信息与桥接器的 VID:PID、USB speed、MSC/BOT 接口。
- 音乐 CD 可以读取 TOC 并尝试提取单条音轨。
- 空白 CD-R/RW 查询可用写速率，不能仅依据铭牌最高速率断定刻录可行。

### M1：ESP32-S3 光驱识别

- ESP32-S3 枚举 USB 设备，提供稳定 VBUS 供电并显示设备 VID:PID。
- 获取 MSC 接口信息，通过 BOT 发送 INQUIRY、TEST UNIT READY；输出真实返回值及 sense 信息。
- 可重复插拔/上电测试，无异常重启、资源泄漏。

### M2：数字 CD 音频读取

- READ TOC 正确获取曲目数和 LBA。
- READ CD 获取至少一段有效 2352 字节/扇区 CD-DA 数据。
- 对比参考提取文件数据（考虑驱动读取偏移与校验差异），测试连续读取。

### M3：立体声播放

- 以 44.1 kHz / 16-bit / stereo PCM 输出到 I²S DAC。
- 左右声道分别验证，支持播放/暂停/上一首/下一首。
- 四键有声方案使用 GPIO1 播放／暂停、GPIO2 上一曲、GPIO42 下一曲，常开按键到 GND，仅播放器模式可用；30 ms 消抖、长按单次、上电先释放，手动首尾循环选曲；只有一条可播放音轨时换轨不改变状态。播放键在停止时启动连续播放、播放／缓冲时暂停、暂停时从原位置恢复；换轨后开启连续播放，暂停中换轨仍保持暂停，目录失效／fault 不保留动作。见[四键接线与验收](playback-controls.md)。
- 四键有声方案用 GPIO41 常开轻触按键触发退盘（GPIO7 保留给 DAC DIN；历史查询配置默认退盘仍为 GPIO7）：消抖、长按只触发一次、上电按住不触发；播放中先关闭输出再退盘，重插盘不自动播放。须以实际碟片退出、真实 USB 返回和无异常复位验收，见[接线与测试](eject-button.md)。
- SH1106 128×64 OLED 使用 GPIO10 SDA／GPIO11 SCL，显示当前实际轨号及播放／暂停／停止／缓冲／欠载／故障；无有效目录清除旧轨号。缺屏或 I²C 失败不阻塞播放，软件时钟显示无声音标记；实屏按 [OLED 验收步骤](oled-display.md) 检查。
- 连续播放到盘尾自然结束时，音频排空并关闭输出后选回首条可播放音轨、保持停止；再次播放从盘首开始。手动暂停／停止和故障不触发此复位。
- 整张测试盘播放不中断或有清晰、可诊断的异常记录。

### M4：CD-R / CD-RW 刻录研究（不保证实现）

- 确认桥接器透传写入 MMC 命令及光驱/介质允许的最低写入速度。
- 实测 ESP32-S3 USB 有效吞吐、可持续缓冲和设备 underrun 保护能力。
- 仅在前置条件通过后，先写单轨数据 CD（ISO 镜像），读取校验、封盘，再考虑 Audio CD。
- 默认不在未知介质上执行写入、擦除、封盘。

## 暂不包括

- DVD 视频解码、高清视频输出、联网流媒体、复杂 UI。
- 量产 PCB、外壳设计、完整 CD 刻录产品承诺。
- 把商业音频内容或受保护光盘镜像放进仓库。

### 连续播放缓冲与恢复

启用 PSRAM 播放 profile 时，使用 2 MiB 软件队列、3 秒预填，USB/I²S DMA 保留内部 RAM。软件欠载自动重缓冲，保留源游标、在途读取与已授权的连续模式；暂停、停止、换轨、设备失联和真实源/输出错误可阻止恢复。记录完成读取耗时及慢读取次数，控制日志开销。验收须分别记录受控供数暂停恢复、正常连续播放和真实 USB 故障，不能合并为无缝或整机稳定性通过。见 [ADR-0017](decisions/0017-psram-rebuffer.md)。
