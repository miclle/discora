# Discora — 需求与验收标准

## 项目定位

以 ESP32-S3 为主控，通过 USB Host 控制标准光驱，实现不依赖 PC/Linux 的独立低成本 CD 播放器；研究进一步的 CD-R/CD-RW 刻录能力。

## 必须满足的约束

- 首版 MCU：ESP32-S3，首测光驱：MATSHITA DVD-R UJ-898 + SATA-USB 桥接器。
- 音乐 CD-DA：44.1 kHz、16-bit、**左右独立双声道**；不得错误混为单声道。
- 首版优先通过 I²S 外接立体声 DAC 输出线路级音频。
- USB 光驱供电与 MCU 控制/数据分开评估；光驱启动或进出盘时不能让主控反复掉电。
- 固件不依赖树莓派、Linux、外部服务器或手机；PC 仅用于调试、刷机和预验证。
- 记录对不同光驱、USB 桥接器和介质的兼容性，不因某一组合成功而推断普遍兼容。
- 设备应可复现地从空白开发板刷入并启动。

## 分阶段功能与验收

### M0：USB 桥接与供电事实确认

- 确认 UJ-898 能被 Linux 识别（实验辅助）。
- 查询识别信息与桥接器的 VID:PID、USB speed、MSC/BOT 接口。
- 音乐 CD 可以读取 TOC 并尝试提取单条音轨。
- 空白 CD-R/RW 查询可用写速率，不能仅依据铭牌最高速率断定刻录可行。

### M1：ESP32-S3 光驱识别

- ESP32-S3 枚举 USB 设备，提供稳定 VBUS 供电并显示设备 VID:PID。
- 获取 MSC 接口信息，通过 BOT 发送 INQUIRY、TEST UNIT READY；输出真实返回值及 sense 信息。
- 可重复插拔/上电测试，无异常重启、资源泄漏。

### M2：数字 CD 音频读取

- READ TOC 正确获取曲目数和 LBA。
- READ CD 获取至少一段有效 2352 字节/扇区 CD-DA 数据。
- 对比参考提取文件数据（考虑驱动读取偏移与校验差异），测试连续读取。

### M3：立体声播放

- 以 44.1 kHz / 16-bit / stereo PCM 输出到 I²S DAC。
- 左右声道分别验证，支持播放/暂停/上一首/下一首。
- 上一曲／下一曲使用 GPIO8／GPIO9 常开按键到 GND，仅播放器模式可用；30 ms 消抖、长按单次、上电先释放，首尾不循环。暂停／停止换轨从目标轨起点播放，目录失效不保留动作，见[接线与验收](track-buttons.md)。
- GPIO7 常开轻触按键触发退盘：消抖、长按只触发一次、上电按住不触发；播放中先关闭输出再退盘，重插盘不自动播放。须以实际碟片退出、真实 USB 返回和无异常复位验收，见[接线与测试](eject-button.md)。
- 整张测试盘播放不中断或有清晰、可诊断的异常记录。

### M4：CD-R / CD-RW 刻录研究（不保证实现）

- 确认桥接器透传写入 MMC 命令及光驱/介质允许的最低写入速度。
- 实测 ESP32-S3 USB 有效吞吐、可持续缓冲和设备 underrun 保护能力。
- 仅在前置条件通过后，先写单轨数据 CD（ISO 镜像），读取校验、封盘，再考虑 Audio CD。
- 默认不在未知介质上执行写入、擦除、封盘。

## 暂不包括

- DVD 视频解码、高清视频输出、联网流媒体、复杂 UI。
- 量产 PCB、外壳设计、完整 CD 刻录产品承诺。
- 把商业音频内容或受保护光盘镜像放进仓库。
