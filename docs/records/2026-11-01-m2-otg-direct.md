### 用户补充：插入主数据头后反复启停

用户报告：光驱接 OTG 时“转一下停一下”；从 OTG 的 USB-A 母口拔掉光驱主数据头、保持辅助供电时，光驱反而能持续旋转。这是用户观察，未测量电压、电流或转速，也不等于持续读取正常。接入主数据头同时改变 USB VBUS/地的连接及主机通信，不能据此单独排除供电，或认定是固件主动停止电机。

核对当前默认探测路径：只发送身份/就绪/sense/目录查询，没有 START STOP UNIT；`device closed` 是处理 USB `DEV_GONE` 后释放 handle，不是定时主动断开。确认重接后的原始日志另有启动后 606 ms 的 `HUB: Root port reset failed`；这是 ESP-IDF 的 root-port 日志，不表示外部 Hub 仍在链路中，也不足以确定掉线根因。

已请求无需换电源或改固件的复位键对照：COM 与辅助供电保持连接，在光驱主数据头拔出时按住 RST/EN，再接回主数据头，观察约 10 秒；松开 RST 后再观察约 10 秒，分别记录是否启停。供应商原理图中 RST 接 CHIP_PU，5V VBUS 不是由该按键切断。本次不打开串口，避免串口控制信号影响这组观察。

用户随后明确反馈：按住 RST 和松开后的两个阶段光驱都没有转。该轮没有复现此前接入时反复启停的现象，也没有电压或总线记录；旋转与否不等于有电/无电或就绪/未就绪，不能将其判为已排除主控影响或已确认供电故障。随后恢复“拔掉插在 OTG 母口的 USB-A 插头、只留辅助供电”的基线，用户确认光驱持续转动，且充电宝指示灯亮或不亮时都转动。因此不把该指示灯作为输出开启/关闭的判据；这也不是带载读盘供电合格的证据。

该对照仅帮助区分物理连接即出现的现象和主控运行后出现的现象；即使后者才失败，也仍需区分初始化/桥接兼容性与运行时供电压降，不能据此确认某个根因。当前辅助电源型号/规格仍待补充，没有改接或新增焊接。

随后改为电脑对照：保留当前新 OTG 转接头、光驱和辅助供电，只将 OTG 的 Type-C 端由 ESP32-S3 native USB 移至电脑，COM 保持连接，不接 Hub。用户已确认“OTG 已接电脑”，但确认后的两次 IORegistry 检查均只有 COM `1a86:55d3`，未出现光驱桥接器 `13fd:0840`；`drutil list` 没有光驱条目，`drutil status` 无介质信息。没有取得目录或执行音频读取，不能将这次电脑对照记为成功。设备信息见本地 `pc-after-user-confirm.json`。

已请求在 OTG 的 Type-C 端保持接电脑的情况下，将光驱两个 USB-A 插头都拔下 5 秒，再先恢复辅助供电、开启输出，最后接回 OTG 数据口；如果 macOS 提示配件访问则允许。用户随后再次回复“OTG 已接电脑”，此次检查已出现桥接器和光驱。没有独立确认具体操作时序或是否出现系统提示，因此不把恢复归因于某一个动作。主机替换同时改变 USB 主机和 VBUS 条件，不能单独区分 MCU 协议与供电原因。

### 电脑初始化后接回 MCU：默认查询成功

用户确认按要求只将 OTG 的 Type-C 端接回 ESP32-S3，两个 USB-A 插头及辅助供电保持不动。0.4.3 默认关闭 READ CD 配置取得有效 13 轨目录；一次桥接器枚举、零 device closed、4 次 TUR 成功、READ CD 数 0。最初两次 TUR 后分别收到 `06/29/00` 和 `06/28/00`，随后就绪，没有据此断言物理掉电。

主机采集 78.193 秒，前段光驱仍接电脑；MCU 日志在 47.346 秒枚举光驱、57.736 秒首次就绪、57.826 秒目录有效，最后一次成功 TUR 在 73.276 秒。不能将整个 78 秒都记为 MCU 已连接稳定窗口。此轮 RTS 复位在光驱仍接电脑时执行，不是独立断电冷启动。

该结果显示在本次电脑初始化后保留辅助供电的条件下，MCU 基础查询可以成功；没有证明此前反复离线的根因。接着另存一轮备份和日志，在相同供电连接下复用 0.5.0 直连实验镜像，短探测通过，但仍在末轨 LBA 223917 返回命令失败、REQUEST SENSE 超时，完整首轨和缓冲未进入。结束恢复默认关闭实验的 0.4.3，5 次 TUR 成功。详见 [后续直连记录](2026-11-01-m2-otg-after-pc.md)。首次直连失败日志继续保留，不覆盖。

此前 0.4.2 的 600 秒顺序读取、105840000 字节与电脑摘要一致仍是独立历史结果，见 [长时记录](2026-10-31-m2-stream.md)。本次没有覆盖或扩大该结论。
