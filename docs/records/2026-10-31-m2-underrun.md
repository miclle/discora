# 2026-10-31：欠载负向测试准备与提前离线

结论：新增默认关闭的欠载注入开关和直连对照配置，三种配置构建通过。本次负向实验在注入前收到设备离线事件，**欠载分支未验证通过**；消费端响应停止、环形缓冲释放已观察到。随后恢复默认关闭的 `0.4.3-underrun-bench`，目录有效，未发送 READ CD。

## 范围与前置证据

沿用 ESP32-S3 + UGREEN Hub `05e3:0610` + 桥接器 `13fd:0840`、UJ-898 / HC10、同一 13 轨音乐 CD。仅匹配 Discora COM 的 VID:PID 与序列号；其它项目串口未操作。现有供电、Y 线隔离及失联根因继续保留未验证边界。

此前 `0.4.2` 的 600 秒顺序实验、105840000 字节和电脑完整摘要对照仍为 [独立已完成记录](2026-10-31-m2-stream.md)；没有把该结果重新标记成当前版本已完成的实验。本次没有重跑远距离寻道或回读 LBA 0。

## 实现

- 新增 `CONFIG_DISCORA_CDDA_UNDERRUN_TEST`，默认关闭，仅允许在扩展实验开启、寻道/完整首轨阶段均关闭时选择。
- 使用真实 READ CD 数据和软件消费端，消费启动两秒后，计划暂停生产者 1200 ms。消费端继续按时钟读取，由实际队列不足触发原有欠载逻辑，不直接填写欠载统计，也不伪造设备返回。
- 正常流测试仍必须判失败；单独的 negative-control PASS 要求注入已发生、恰好一次真实欠载、缺失字节大于零、消费任务完成及源服务无故障。它不表示音频播放或正常流通过。
- 修正未能等待消费端停止的路径：保留缓冲并立即返回，不再读取仍可能变化的统计/摘要。该未退出分支本轮仅检查源码并构建，未人为阻塞消费任务以触发。
- 将消费任务栈余量扫描移出队列临界区。

## 本轮真实结果

ESP-IDF v5.4 (`67c1de1eeb`)，Xtensa GCC 14.2.0；分别执行目标设置与构建，默认关闭、负向实验、直连对照三种配置均通过。USB 接收和环形缓冲使用内部 RAM，不将 PSRAM 作为 USB DMA。

短探测通过后，从 LBA 414 顺序衔接，预填耗时 115155 μs。随后约 1.08 秒时，源服务报告设备离线，早于两秒注入点；没有出现暂停注入日志。

```text
I (5092) cdda_bench: buffer prefill complete elapsed_us=115155 free_internal_heap=170652
I (6172) cdda_bench: buffer failed seconds=60 produced=319872 consumed=188556 underruns=0 missing_bytes=0 low_active=111324 high=148368 longest_read_us=17291 sink_max_late_us=0 transitions=0 joined=1 sink_stack_free=1096
I (6192) cdda_bench: negative-control FAIL underruns=0 missing_bytes=0 joined=1 ring_released=1; not a normal streaming PASS
I (6202) cdda_bench: extended bench failed negative_control=1 seeks=not_run full_track=not_run (software sink only; not I2S playback)
I (6322) usb_probe: device closed; free internal heap=326368
```

- 60 秒是配置目标，不是完成时长；只运行约 1.08 秒消费。生产/消费字节数和摘要不一致是未完成窗口，不能判完整数据流通过。
- 主机采集 16.253 秒，单次 MCU 启动；欠载数 0、缺失 0，没有注入，负向结果正确保留 FAIL。
- 消费端已发布完成、不再访问环形缓冲，日志报告 `joined=1`、`ring_released=1`。这只覆盖本次源离线后的退出，不代表所有超时/隔离路径均通过。
- 本次未取得用户对期间物理操作的独立确认，也未测量供电；只记录设备离线事件，不推断自动故障原因。
