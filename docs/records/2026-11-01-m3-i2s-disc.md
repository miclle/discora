# 13 轨 I²S 空载整盘验证

状态：单张 13 轨 CD 的 I²S 空载整盘实验通过（bench-tested）；真实 DAC / 波形仍未验收。

2026-11-01，0.7.5-eof-report（固件提交 `86d418a`），ESP-IDF v5.4；ESP32-S3 N16R8、UJ-898 HC10、桥接 `13fd:0840` Full-Speed BOT，COM `1a86:55d3` / `5CF9109063`。OTG 直连、辅助供电、同一张 13 轨音乐 CD 均不变；GPIO4/5/6 空载，没有 DAC。

本轮使用 `cd-player-i2s-observe.defaults` 和显式 `--sink i2s-unloaded` 的整盘工具。目标 594221040 字节，13 轨各自 EOF 后关闭，再由电脑脚本选择下一轨；不是固件自动换轨，也不是无缝输出。

验收覆盖源/软件消费摘要、I²S 提交字节、供数与 EOF 阶段事件计数、错误/欠载、通道释放、关闭后计数稳定和资源观测。完成事件包含自动补零，不等于有效 PCM 已经全部到达引脚；真实波形、时钟精度、模拟 L/R 和听音均未验收。

13 项工具离线检查通过，新增显式 sink 核对、缺失阶段/供数溢出/错误提交长度拒绝及收尾计数保留。原始证据位于 `.local/bench/2026-11-01-m3-i2s-disc/`，部署脚本最终恢复 0.4.3 查询模式；运行结果和恢复情况如下。


## 结果

- 场景 3414.481 秒（约 56 分 54 秒），13 轨、31586 次 READ CD；源 / 软件消费 / I²S 提交均为 594221040 字节。
- 逐轨源/消费摘要一致，并且全部与上一轮 0.7.2 软件时钟整盘摘要相同；未新增电脑端独立整盘参考。
- 写入错误 0、坏 DMA 长度 0、软件欠载 0、报告丢弃 0；未观察到 USB 离线、传输错误或异常复位。
- 每轨供数阶段事件溢出增量 0，排空阶段各 2 次，累计 26 次完整保留；各轨停止后计数稳定。
- 每轨只打开一个 I²S 通道，最终 opens=closes=13、handle=0、tx=closed；显式短预装补零为 0。最终 DMA 完成块数 336877，包含收尾自动静音，不能换算成有效 PCM 输出量。
- 覆盖 588 / 1176 / 1764 字节末块。实际排空等待 57076–57876 μs，仍使用 50 ms 截止，差值来自任务调度；不作物理尾音完整性结论。
- 所有轨末 heap_free=159360 字节，最终 heap_min=151316、output_stack_min=3872 字节；有限窗口未见轨间持续下降。

实验后恢复并写入校验 0.4.3 默认查询模式。25.190 秒取得有效 TOC、5 次 TUR 成功、READ CD 数 0，无离线或传输错误；串口释放后才进入下一阶段实现。

`scenario/report.json` 保存逐轨摘要、状态与六阶段快照；`checks.json` 核对总量、通道、与上一轮摘要的一致性和恢复结果，`sha256-manifest.json` 关联日志与产物。没有保存音乐 PCM。此轮仍由电脑脚本逐轨选择，不构成固件自主换轨证据。
