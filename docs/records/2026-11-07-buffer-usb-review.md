## 审查范围与结论

以 `332b384` 为基线，检查本地暂存、未暂存和相关未跟踪文件，按播放器改进、USB 诊断、对照实验三组拆分。共享文件按功能拆分；每组从实际 Git index 导出独立固件源码快照进行验证，工作目录保留最终版本。没有将本地构建输出、串口原始日志、Flash 备份或 CD PCM 加入提交。

**未发现可确认的、需要阻止本次提交的代码缺陷。** 本轮未修改播放器或 USB 算法；补齐 USB 诊断、120 秒／零等待查询和无声读取的 CI 构建配置，修正 README／播放说明中的过时部署与验收描述。审查重点如下：

- 自动重缓冲保留源游标、代次、在途读取和未消费 PCM，输出 owner 先关闭 I²S；暂停、停止、换轨、介质失效及真实源／输出故障可阻止恢复。测试覆盖在途读取在重缓冲前后返回以及短 EOF。
- USB transfer 只由真实回调归还所有权；诊断快照不将超时后的迟到回调改判为成功，也不新增重放或端口复位。记录命令各阶段与真实错误前的播放器快照。
- 根端口链接包装限制到 ESP-IDF 5.4；离线测试与实际诊断 ELF 均确认原 HCD 处理函数只被调用一次、事件值原样返回。关闭诊断时不启用该链接包装。
- A/B 实验默认关闭，只允许识别／就绪／sense／目录查询；停止、失败和完成为锁定终态，重连不重新授权。控制台禁用播放／换轨，零等待不会缩短后续 120 秒查询窗口。
- 2 MiB 队列仅用于普通 PCM，USB／I²S DMA 与 ISR 计数器仍保留内部 RAM；无 PSRAM 的默认配置保留原队列。故障注入默认关闭，正常模式启动仍为 stopped。
