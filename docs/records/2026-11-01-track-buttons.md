# GPIO8／GPIO9 换轨按键：实现与软件验证

- 日期：2026-11-01
- 固件：`0.9.1-track-buttons`
- ESP-IDF：v5.4；目标：esp32s3
- 状态：implemented；未烧录、未进行真实按键／CD 换轨／DAC 验收

## 实现范围

GPIO8 上一曲、GPIO9 下一曲，常开按键接 GND、内部上拉，仅播放器配置默认启用。复用原退盘消抖核心，原算法不变，移名为 `button_core`。播放器输出任务轮询，持原互斥锁执行 `cd_player_step`，成功后关闭旧输出，边界拒绝不影响现有音频。旧在途回复沿用代次拒收。

30 ms 双向消抖、上电先释放、长按单次；双键冲突后要求两键稳定释放。无有效音频目录或 fault 时不保留手势；介质发布／失效在同一锁内重置按键。上一曲／下一曲从目标轨开头播放，首尾不循环，成功换轨取消连续播放。没有新增 USB 命令或设备访问任务。

## 离线检查

`python3 firmware/tests/run_host_tests.py`：**10 组 C ASan/UBSan 检查通过**。新检查使用合成目录／PCM 与实际按键核心、播放器核心，覆盖：

- 按下抖动、30 ms 门槛、上电按住、长按不重复及双键冲突／释放抖动。
- 无盘插盘和 fault 恢复时按住不延迟执行，介质更换清除部分手势。
- 首尾不循环、边界拒绝保留代次和已有 PCM、跳过数据轨。
- 停止／暂停时选择目标轨并开始预填、手动取消连续模式。
- 换轨清旧队列、旧在途读取回复被拒收。

原退盘检查全部通过；原有协议、缓冲、音频核心、恢复编排、I²S 替身、USB 等待及 50 万步状态组合也通过。以上均为离线软件证据，不是 GPIO 电气、USB 实盘或声音输出验收。

## 设备与交付边界

本轮未打开串口、未烧录、未触发光驱动作；当前部署证据仍为 0.9.0 默认查询／退盘配置，见[部署记录](2026-11-01-button-eject-deploy.md)。历史 UJ-898 / HC10、桥接 `13fd:0840` 和音频 CD 实测不作为本版本按键换轨证据。

实体按键、真实 READ CD 换轨和旧读取丢弃、播放中退盘、重插盘、I²S／DAC 声音切换均须按[接线与验收](../track-buttons.md)另行完成。本轮无提交、推送或远端 CI。
