# 播放器固定种子状态组合测试

2026-11-01，测试直接调用生产 `cd_player_core` / `audio_core` / `pcm_buffer`，不打开任何设备，不修改播放器运行逻辑。

100 个固定 xorshift32 种子，每种 5000 步，共 500000 个动作。组合 play、pause、stop、换轨/非法轨、读请求、延迟/失败/短回复、重复返回、消费、介质失效/重新发布。最多保留 8 个跨代次待返回请求，用独立的线性 FIFO 预期数据与生产环形缓冲输出逐字节比对；不复用被测环形缓冲作为预期实现。

每步检查容量、4 字节对齐、代次非零、请求扇区/轨界、当前 pending 所属代次、数据轨拒绝，以及旧回复不清除较新的 pending。调度权重保留足够读取/消费机会，验收同时要求实际覆盖 EOF、fault 和 underrun，避免只做控制切换却没有读完任何轨。

结果：有效接收 7174，旧/失败回复拒绝 13090，实际消费动作 10337，正常 EOF 111，进入 fault 4809、underrun 328；均为合成用例，不是实盘故障次数。八组 C ASan/UBSan 检查通过，本轮没有发现新的生产核心缺陷。

本地 `.local/bench/2026-11-01-m3-state-sequences/` 保存测试输出、源码快照与摘要。固定种子便于复现，但不能证明所有调度组合或真实多核竞态均已覆盖。
