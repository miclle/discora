# I²S 空载实机与日志对照

## 范围

ESP32-S3 N16R8，I²S Master / Philips / PCM16 stereo，GPIO4 BCLK、GPIO5 LRCK、GPIO6 DATA 保持未连接 DAC。COM `1a86:55d3` / `5CF9109063`；光驱 UJ-898 HC10、桥接 `13fd:0840`、同张 13 轨 CD-DA、OTG 直连与辅助供电不变。ESP-IDF v5.4 (`67c1de1eeb`)，仅应用 `0x10000` 刷写，预先核对唯一 COM、当前查询应用及分区/备份。

`on_sent` 用无锁 32 位原子计数完成块和异常长度；`on_send_q_ovf` 单独计事件队列溢出。ISR 不打印、不触碰播放器/USB。任务侧另外统计实际提交 PCM、短预装补零、写入错误、通道打开/删除。计数跨暂停重开累计；DMA 回调可能对应自动补零，不代表全部是有效音乐，也不等价于测得 DAC 或 GPIO 波形。当前配置未启用 I2S ISR IRAM-safe。

## 测试音对照

同一序列：left、right、stereo、silence，分别持续约 1.5 秒观察回调增加；pause 后观察提交量与 DMA 不再增加，play 后恢复，stop 后句柄释放。没有接音箱，没有听音。

| 配置 | 耗时 | DMA 完成块 | 事件队列溢出 | 写入错误 | opens / closes |
| --- | --- | --- | --- | --- | --- |
| 0.7.0，输出任务同步状态日志 | 12.644 s | 957 | 5 | 0 | 5 / 5 |
| 0.7.1，仅增加 UART TX 缓冲 | 12.750 s | 961 | 5 | 0 | 5 / 5 |
| 0.7.2，独立日志任务、测试音供数优先级 3 | 12.731 s | 969 | 0 | 0 | 5 / 5 |

第一轮发现溢出，第二轮没有改善，因此不采用 UART TX 缓冲方案。最终用 8 项有界快照队列、低优先级日志任务，音频任务只格式化并以零等待入队；满队列/超长报告明确计入 dropped，不阻塞供数。测试音供数优先于日志输出。此对照支持日志/供数调度相关性，不能仅凭队列计数推断实际丢失了多少音乐帧。

三轮均恢复 0.4.3 查询模式，独立观察约 25 秒取得目录，无 READ CD。分别保存于本地 `.local/bench/2026-11-01-m3-i2s-empty/`、`2026-11-01-m3-i2s-buffered-tone/`、`2026-11-01-m3-i2s-deferred-tone/`。保留失败假设与源码/镜像快照，没有覆盖为成功记录。

## CD 源空载

使用 `cd-player-i2s-observe.defaults`，上电 stopped。先短时播放、暂停/重开、停止，再从首轨起点完整运行；每段单独记录代次与源/软件消费摘要。原始证据保存于 `.local/bench/2026-11-01-m3-i2s-deferred-cd/`，包括应用、源码、日志、`checks.json`、恢复采集及摘要。

完整 CD 实验窗口 275.638 秒。首轨生产/软件消费均为 45565296 字节，摘要 `73ad449e02aa5513ffb632bfd632a2bf6bc048dabb675b4ba958b26e9a54a38f` 一致，最后块 1176 字节；完整段适配器 PCM 提交增量同为 45565296。包含前置暂停/重开测试的累计 DMA blocks=26196、opens/closes=3/3、handle=0、write_errors=0、bad_dma_sizes=0、软件 underruns=0。EOF 后再次观察 DMA 和读取计数均不再增加。

周期采样的稳态 event_overflows 均为 0，EOF 收尾停止供数后的最终计数为 3。50 ms 软件等待及摘要日志期间，DMA 会继续自动清零循环且完成事件无人消费，队列可以溢出；本轮没有用 DMA buffer 内容追踪来证明具体溢出时每块对应的数据，不能据此断言有/无有效 PCM 丢失，也不把固定等待当作硬件排空测量。尾音完整性与引脚波形仍待验收。

最后恢复默认查询 0.4.3，25.201 秒内目录有效，无 READ CD/离线/传输错误，串口释放。主机六组 ASan/UBSan 检查通过；0.7.2 测试音、CD I²S 观察和软件时钟配置均 set-target/build 通过。未连接 DAC，未验收模拟声道、时钟精度或听音。
