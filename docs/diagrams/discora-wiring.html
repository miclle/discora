01 · 整机连接与供电

原台架模块级总览，保留 COM 与原生 USB 插头路径；不能与下方的双路 5V 改接方案混接。框内信号逐线连接，不表示短接；虚线支路须先确认规格。单独打开整机总览 SVG。

USB 直连 · 双路 5V 与防回灌

A 只供主控，B 供桥接器与光驱；USB 的 5V 留在 B 支路，所有 GND 共地。

2026-11-10 改接方案：planned，未改实物、未做带载验收。 这一节替代原台架的 USB 插头与供电接法，仅在完成线束改造及检查后采用。按 ESP32-S3-COREBOARD V1.4 图纸核对；端子位置为示意，以实物丝印为准。

① USB 线怎样改

移除主控端原 USB 插头／OTG 转接头，保留通往光驱桥接器的一段线。桥接器侧的 VBUS（常见红线）接 B OUT+；D−、D+、GND 分别接 GPIO19、GPIO20、主控 GND。

不是把光驱的 VBUS 悬空：桥接器仍从 B 得到有效 5V。主控板 USB2 VBUS 不接这根红线，也不接 B。

保留 D+/D− 原双绞结构，剥开的末端尽量短；不经洞洞板长散线。用短、足额的独立正负电源线供光驱，其大电流回路直接回 B OUT−。

② 辅助电源怎样处理

拔掉原充电宝／充电器及辅助 USB 插头。若保留分叉线，将不用的插头移除或逐芯绝缘封住；不能留下带电裸触点或可误插电脑的插头。

断电测辅助 5V 与 USB VBUS 是否连通。若光驱还需要辅助入口，两入口都只能从同一个 B OUT+／OUT−分支供电；确认它们均为 5V 输入后再接。

原插头线芯若已剪断，两端分别绝缘。不要把屏蔽层／裸排流线当作唯一的 GND 回路。

③ 电脑与板载焊桥：明确两种工作状态

状态A / B 与直连线电脑连接
电池独立播放按上图；A、B 由同一总开关控制COM、原生 USB 均不插电脑；无外部辅助电源
只烧录主控关总开关，拔开 A OUT+ → 5Vin；拔开光驱 D− / D+ / GND 三线接头再连接 COM，由电脑单独供主控；原生 USB 留空

图示方案的目标焊桥状态：IN-OUT 断开、USB-OTG 断开；若 USB-OTG 已焊通，全部断电后移除焊桥并核对。IN-OUT 旁路 D3，USB-OTG 旁路 D2；两者都不是稳压器或限流器。

V1.4 图纸中，5Vin 经 D3 向板内 5V 供电；COM VBUS 经 D1 向板内 5V 供电，CH343P 还取电于 COM VBUS。本图用“拔开供电线／不同时接电脑”消除外部电源并接，不依赖未核验的实物二极管；不把“剪掉 COM 红线”作为通用调试办法。

烧录结束后先拔掉 COM，再恢复 A 供电线与光驱三线接头，最后打开总开关。边播放边调试需另行核对 COM 电源隔离及板载 CH343P 的供电／引脚状态；不能直接并接另一只 USB-UART 的 TX，以免与板载发送端争用或经信号线给断电器件供电。

上电前与首次验证

  1. 全部断电：核对模块实物 IN± / OUT±，用通断档确认线芯及 GND；不得有 A OUT+ 与 B OUT+ 的直接导通路径，也不得让 B OUT+ 通到主控 5Vin、板内 5V 或 USB2 VBUS。二极管、电容会影响读数，不能只凭一次蜂鸣判断隔离。
  2. 分支单独上电：先拔开 USB 数据三线，再分别只给 A、只给 B 输入供电，确认另一支输出没有被抬升至供电电压；分别测空载输出及主控板内 5V / 3V3。D3 有正向压降，板内电压需实测。
  3. 恢复整机接线后同时供电：检查枚举、启动／进退碟、寻道及连续播放。测 B 输出和光驱端的最低电压、峰值电流与模块温升；DCE001 标称 3A，但供应商要求无散热时在 2A 内，当前负载能力未验收。

本方案避免的是 A、B 与电脑之间的外部 5V 回灌路径，不提供电气隔离，也不保证消除 USB 掉线。充电、功放和 DAC 支路未画入，不据此扩展接线。

四键线束 · 连续排针与逐孔装配

采用 0.12.1-buttons-row 四键 profile。保留 I²S GPIO15／16／7、OLED GPIO10／11、USB Host 和 COM；四个按键均常开接地。如下五芯从已有 J2 排母底部焊脚引出，P3 接头在板外，不新增板面插座位置。

  1. 全部断电，按模块 GPIO 丝印确认 J2-4／5／6／7 及 J2-1；不得用 GPIO 数字猜排针序号。
  2. 按孔位总图，从（M，A）、（N，A）、（O，A）、（P，A）引出四根信号，从（J，A）引出公共地；排母顶面留给模块插拔。
  3. 背面焊脚分别焊短绝缘线，沿后缘出板；不跨天线、USB 插头或 BOOT／RST。用 P3 连接前面板五芯，接头两侧标记芯号并做应力固定。
  4. 检查每根信号到对应按键导通，松开到地不通、按下到地导通；相邻信号无短路。共地仅用于按键回路，不承载光驱／功放电流。
  5. 接线、烧录和实体操作按用户安排留待后续；当前机内 CAD 包络未计入 P3 和完整线束，不据此裁板或确认装机。

03 · 原台架 GPIO15/16/7 可拔插洞洞板

本节仅对应原 120 × 80 mm 台架板。 上方 100 × 55 mm 机内候选不沿用本节孔位或裁剪尺寸。

沿用 120 × 80 mm、30 列 × 42 行的洞洞板与原三条排母位置。ESP32 和 DAC 插在排母上；只焊载板侧导线。光驱、功放及电源模块保持板外，USB 继续使用板载接口与现有 USB 线。

当前接法：GPIO15→BCK、GPIO16→LCK、GPIO7→DIN。GPIO7 不接退盘键；GPIO4 留空，不再接临时测量线。当前有声配置关闭按键和 OLED，默认 GPIO4/5/6 固件不能直接用于本图。

安装顺序与保留空间

  1. 全部断电，用模块定位排母，先点焊两端再试插；模块方向是 ESP32 天线朝上、USB 朝下，DAC 输入朝右、音频口朝左。
  2. 只焊排母焊脚与 W1～W7；信号线走载板背面，尽量短，交叉处保留绝缘。模块保持可拔，不用焊锡将模块排针与排母封死。
  3. 装 P1，按两端的 +5V / GND 标记连接原 DAC 电源；制作 P2 音频短线，按 L / AGND / R 对接原功放。线束作应力固定，避免拉扯 DAC 焊盘。
  4. USB 下方保留整条插拔通道，先试插现有两根 USB 线；不用散线把 D+/D− 引到洞洞板。BOOT / RST 上方和 DAC 焊桥处保持可操作。
  5. 在新焊接处检查 W1～W10 端点导通和相邻针无短路，再恢复原供电。本次装配后的检查针对新增焊点，不要求重做此前全部无声排查。

背面视角：所有坐标仍按元件面原孔身份。左右翻板、顶部朝上时，原 X=4 列在左侧；不按背面印字重新编号。先在两面标出同一个 X=4 / Y=A 孔。

扩展预留：左下区域先留空；按键、OLED、供电转换模块不在本次新增接线范围。顶部三行空孔可能被天线端投影覆盖，不代表已满足射频净空。

装配边界与依据

GPIO15/16/7 音频连接已通过台架播放，USB 长时仍有失联；本图不把载板装配当作 USB 故障修复。供应商 V1.4 图纸和参考照片给出 J1-7/8/9 对应 GPIO7/15/16；从排母首孔 Y=D 推导为 J/K/L，仍以手边模块丝印试插定位。
