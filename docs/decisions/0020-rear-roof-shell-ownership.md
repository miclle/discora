# ADR-0020：后斜面与碟口导向并入一体后壳

> 同日后续：[ADR-0021](0021-five-mm-front-panel.md) 将前壳主体加厚至 5 mm、机身深度增至 80 mm；本记录中的旧尺寸与材料转移报告保留为阶段历史，当前尺寸和验证以 ADR-0021 及模型报告为准。

- 日期：2026-11-08
- 依据：用户要求后斜面从一体前壳移出，合并到一体后壳。
- 状态：CAD 分件、材料归属、静态干涉、左右对称及报告注明的拆装路径检查通过；实物打印、配合和拆装未验收。

## 分件

顶部沿提手后表面 Y=41.5 分界。P1 保留前壳、前斜面、完整提手、格栅与屏幕安装座；P2 增加后斜面、碟口及其导向框，继续包含侧壁、后壁、底架、电池托盘、光驱导轨和 DAC 支撑。仍为三个主要 PLA 结构件，不增加独立顶盖。

按用户提供的接缝参考图，两侧交界简化为一条直线：从侧壁前上角 (Y=3, Z=163.451) 接到提手后侧根部 (Y=41.5, Z=190.934)，取消原内轮廓在侧面形成的短平台与回折。仅调整左右各 3 mm 宽侧缘的分件归属，将合计 48.036 mm³ 材料从 P1 移到 P2；外轮廓、中央内顶面及硬件位置不变。左右使用镜像几何，不增加装饰条或额外零件。

`FrontCowl` 与 `RearRoof` 通过同一个 `RearRoofRegion` 刀体从原 `Cowl` 分别相减、取交集；成品 `ConstructionObjects` 同步记录实际归属。`SlotGuide` 完整划入 P2。前后斜面 35.395°、水平宽 36.5 mm、实际斜宽 44.775 mm 和整机 142 × 78 × 215.934 mm 外包络均保留，不改变光驱或操控件位置。

分界采用名义齐平接触，现有四处前壳螺钉保留。未增加卡扣、密封垫或未经实测的打印补偿；提手承载、接缝配合与打印层间强度仍需试片和实物验证。

## 拆装变化

后斜面成为 P2 的固定部分，光驱整件不能再从顶部抽出。先拆 P1 和侧孔、断开相应线束，再拆出 P3；光驱先沿 −Y 前移 11.5 mm，再绕其移动后中心沿 Z 旋转 −30°，同时继续前移 15.75 mm，最后向前抽出；安装按反向路径。旋转后的 X 包络约 115.601 mm，可避让前部连接柱；此方向也避让左侧 DAC。光盘仍从既有碟口竖直进退，不能混淆光盘路径与光驱整件拆装路径。

当前检查见 [validation.json](../../hardware/enclosure/validation.json)、[assembly-paths.json](../../hardware/enclosure/assembly-paths.json) 和 [seam-checks.json](../../hardware/enclosure/seam-checks.json)。[repartition.json](../../hardware/enclosure/repartition.json) 保留接缝简化前的后斜面转移阶段证据，其结果模型是接缝检查的基准。归属检查覆盖后斜面及导向框在 P1 中交叠为零、在 P2 中缺失为零；材料转移核对前壳减少量和后壳增加量一致，接缝两侧另取 14 个位置检查上下归属，不把分件变更视为外形重设计。光驱旋转前后的平移使用连续保守包围盒扫掠，旋转与同步前移采用 61 个实际 B-rep 姿态（0.5° 步长），不声称连续旋转得到严格证明；前壳仍采用既有离散路径采样。

本次不改变固件或电气连接，不补齐尚未建模的洞洞板、完整线束和外围电源模块。
