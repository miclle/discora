# ADR-0041 P3 喇叭封边与可拆出线封堵

> 后续更新：本页记录的旧 P3 悬空问题已在 [ADR-0042](0042-p3-printable-frame-transitions.md) 中修复并重新切片。以下告警及打印文件属于初版历史证据，当前请使用 ADR-0042 文件。

日期：2026-11-14。状态：已实现并通过 CAD 与局部切片检查；后续完整悬空复核发现 18 条未支撑告警，需调整安装框后缘及螺柱后端，当前不可作为打印定稿，见[逐项核对](../records/2026-11-14-p3-overhang-audit.md)。完整件打印、实际密封和声音待验证。沿用 [ADR-0040](0040-wide-chambers-flush-side-ports.md) 的侧孔位置、加宽声腔及背面朝下打印姿态。

## 分工与取舍

P3 承担左右腔壁、隔板、喇叭安装和侧向通道；P2 承担外壳、饰片及侧面出口。保留两件之间每侧 0.7 mm 的滑动间隙，不增加接口密封圈、插接管或压紧机构。

这不是“整机已气密”的结论。侧口之间的开放间隙仍与外壳内部连通；当前侧通道未调谐，不把 P2 当作定容声箱，也不声称此间隙完全不影响声音。若后续测到明显漏声或杂振，再针对实测问题处理。

## 保留通过试装的喇叭安装座

喇叭入口、盆架开口、四孔孔距、盲底螺柱、Y=10 mm 的硬质承托面以及喇叭占位全部保持原样。格栅前间隙仍为 3 mm，后间隙仍为 11 mm。座面下不新增有厚度的垫片，避免改变安装深度和螺钉咬合。

安装时让金属框贴紧原座面并均匀锁紧，在固定框外周与 P3 入口之间的可见缝隙做连续封边。封边材料采用可移除、不固化的密封泥，按实物金属轮廓填缝；不覆盖振膜、悬边、螺钉头或端子，不把材料塞入盆架通孔。拆喇叭前先揭除封边并松开出线封堵，再卸螺钉。

这是装配工艺，CAD 未把软材料当成新增刚性零件或实测压缩垫。材料需由实际产品说明确认与 PLA、金属及线皮兼容，残胶及可移除性待实物核对。例如 [3M Strip-Calk 技术资料](https://multimedia.3m.com/mws/media/277563O/3m-strip-calk-08578-technical-data-sheet.pdf)说明了不固化材料用于缝隙和线束穿孔的用途，但未证明其与本项目全部材料的兼容性；这里未锁定采购型号。

## 出线结构

用户确认端子位于喇叭背面的短边，上下可互换；双芯排线单根外径 1.8 mm。两只喇叭均端子朝上安装。每侧新增一个顶部出线口，只有以下两处切除改变 P3：

| 项目 | 尺寸 / mm |
| --- | --- |
| 中心 X、Y | 左 −59、47；右 +59、47 |
| 顶壁内／外面 Z | 118／120.5 |
| 胶囊形通孔 X × Y | 4.6 × 2.8 |
| 外侧胶囊形封堵槽 X × Y | 8.6 × 6.8 |
| 封堵槽深度 | 0.6 |
| 封堵槽下剩余壁厚 | 1.9 |
| 两根 Ø1.8 线并排时名义径向余量 | 0.5 |

通孔供自由线端穿过，不供预装插头穿过。先接好喇叭端并检查绝缘，将线从喇叭上方引到安装框后方，再转向外侧出线口；从内向外穿出，留检修余量，接功放端。封堵槽填入可移除密封泥，封住孔周、线皮外缘和双线之间的凹缝；封堵不承担拉力固定。导线随 P3 总成移动，不跨接或粘在 P2 上。

右侧检查用路径经过 `(26,24,114) → (26,55,114) → (59,55,114) → (59,47,114) → (59,47,118)`，左侧镜像。按 3.6×1.8 mm 双线包络检查，与名义喇叭和 P3 无交叠。它是可用空间预留，不是要求实线折成直角；端子突出、焊点和最小弯曲半径未测，实际走线应平缓转弯。

封堵槽上方 18 mm 操作区域没有模型碰撞；洞洞板部分遮挡更高处的直达空间。建议先穿线、封堵，再装洞洞板。维修单只喇叭时，先抽出 P3，必要时卸洞洞板以获得手指操作空间，拆除对应封堵并松开功放端线，再抽出喇叭；不用破坏 P2/P3 接口。整个 P3 维护时，内部喇叭线可保留在总成上。
