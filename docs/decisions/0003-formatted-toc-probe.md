# ADR-0003：有界的两阶段音乐 CD 曲目目录读取

- 日期：2026-10-31
- 状态：Accepted；单盘 bench-tested
- 扩展 [ADR-0002](0002-read-only-native-bot-probe.md) 的三命令白名单；原记录保留为 M1 阶段决策。

## 背景与决策

用户已确认插入音乐 CD，基础 BOT 查询能够连续就绪。先验证桥接器能透传 READ TOC，再实施 READ CD；本轮不增加 PCM、I²S 或刻录。

1. 白名单仅新增 READ TOC/PMA/ATIP (`0x43`)，固定格式 0、MSF/TIME=0、起始曲目 0、LUN 0。SCSI CDB 为 10 字节，ATAPI 子类补零为 12 字节，保留只读、无任意 CDB/Data-Out 入口。
2. 先请求 4 字节头，响应长度字段加 2 得到完整长度。只接受 1–99 的顺序曲目和最后一项 `0xAA` lead-out；最多 804 字节。按完整长度再请求，两个头必须一致。
3. 完整目录必须精确匹配声明长度，ADR=1，曲目号连续，LBA 非负且严格递增。全部校验完成后才发布起止 LBA 和 CONTROL 属性。末地址为排他边界；音频/数据按 CONTROL 的 `0x04` 位判断，不在此处假定声道或预加重属性。
4. 就绪后读取一次有效目录。同一就绪周期最多尝试三次；命令失败请求 sense，传输故障沿用原停止/恢复策略；TUR 失败或断连清除目录状态。
5. 仅输出元数据，`MM:SS:FF` 使用 75 帧/秒。它表示相邻轨道起点区间，可能包含间隙，不等同于音频完整性或听感长度。USB 接收缓冲按 MPS 对齐，精确命令长度不变；使用内部内存，默认 main stack 增至 8192 字节。

## 验证与限制

- 主机侧合成测试覆盖 CDB 字节、4–804 字节界限、截断/畸形目录、99 轨上界、音频/数据标记及边界输入；ESP-IDF v5.4 构建通过。
- UJ-898 / HC10 + `13fd:0840` 在单张音乐 CD 上返回有效 116 字节目录，13 条音频轨；[实验记录](../records/2026-10-31-m2-toc.md)。
- 不覆盖 raw TOC、PMA、ATIP、CD-TEXT、负 LBA、复杂多会话；未确认解析的目录不继续读取音频。READ CD 仍未实现。
- 依据：T10 MMC-4 rev 5a §6.30、Table 435 / 438（[T10 文档镜像](https://www.13thmonkey.org/documentation/SCSI/mmc4r05a.pdf)）。仅按标准独立实现，未引入第三方源码。
