# ADR-0034：后壳主体加厚至 5 mm

- 日期：2026-11-11
- 依据：用户要求后壳主体与前壳同厚，并检查内部间隙和装配；确认允许小幅增大外壳，优先保留装配空间。
- 状态：CAD 实现；几何、拆装路径、背锁、OLED、网格及本地切片检查见对应报告；未实物打印或装配。

## 尺寸与保留空间

后壁、左右侧壁、底板与后斜顶统一为 **5 mm**，斜顶沿法向测量。侧饰片仍厚 2 mm，连接筋、导轨、安装座和局部功能结构不按主体壁厚统一。

保持原外形直接向内加厚的试算会侵入电池 2240 mm³、DAC 527 mm³，并与按键支架、P3 和前壳局部交叠，因此没有采用。

采用外扩：左右各 2 mm，后方 2 mm，底面向下 2 mm。内部侧壁仍为 X=±68，后壁内面仍为 Y=77，底板内面仍为 Z=6；电池托盘及全部电子零件、光驱、喇叭和操控件保持原位置。前壳随宽度与底边扩展，仍为 5 mm，前后壳底角保留 R4。脚垫随底面下移 2 mm，仍外露 3 mm。

两斜肩仍为 35.395°、水平宽 38.5、斜宽 47.229。左右按 X=0 镜像；内部 DAC 支撑保留原不对称例外。前壳操控区外斜面、屏幕和按钮位置不变，提手随屋顶交汇后移 1 mm、上升 0.711 mm，前壳接缝与后壳顶点直接相接。

侧孔外观随侧面向外移 2 mm，短管向内延长至原 X=±65.3 接口位置；P3 声腔外包络保持。仍为 0.3 mm 轴向名义间隙。四点连接和 2 mm 饰片保留，通流截面重新采样；管长增加不能视为声学性能不变，尚未调谐。

## 间隙与装配

| 检查 | 结果 / mm |
| --- | --- |
| 电池前 / 后内壁 | 1 / 1，保持 |
| 电池顶部至 P3 | 3.5，保持 |
| 电池下方绑带空间 | 2，保持；绑带未建模 |
| DAC PCB 至侧壁 | 1，保持 |
| 后斜顶至光驱最小距离 | 1.659；此前 2.501，减少约 0.842 |
| 侧孔至声腔 | 轴向 0.3；当前实体最短距离约 0.424 |
| 下方背锁工具伸入深度 | 67.8；此前 65.8，选至少约 68 mm 有效刀杆 |

后斜顶加厚后，原光驱拆卸侧转路径末段与后壳发生小量交叠。最终路径为：先前移 11.5 mm，然后绕 Z 侧转 −30°，同时再前移 **17.75 mm**（此前 15.75），最后向前抽出。不能直接把第一段改成 13.5 mm，该试算会提前碰到 DAC 元件预留。

拆装仍需先断线、卸对应螺钉与绑带。P3、电池使用连续保守包围盒扫掠；光驱前后平移段使用连续保守扫掠，侧转段以 0.5° 采样 61 个实际 B-rep 姿态；前壳按 1 mm 步长前移检查。离散采样不等于连续运动证明。
