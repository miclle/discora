# ADR-0012：独立 SH1106 播放状态显示任务

- 日期：2026-11-04
- 状态：Accepted；implemented，实屏未验收

按已有 GPIO10 SDA／GPIO11 SCL 接线及模块结构图实现 SH1106 128×64 I²C 显示。原始资料同时提及 SSD1306，实物型号未知；不混用两种控制器的 charge-pump／寻址命令，也不因地址 ACK 声称自动识别。默认 7-bit 0x3c，可配置 0x3d；可见区按 SH1106 显存列偏移 2 实现，方向与偏移待实屏确认。

使用 ESP-IDF v5.4 原生 I²C master，无新增第三方依赖。字体为本项目绘制的 5×7 大写字符／数字；两倍显示轨号与状态，不引入中文字库或尚未实现的 CD-Text。播放器模式默认启用，可配置关闭；默认查询与测试音不启用。

播放器仍拥有状态，显示端通过同一 mutex 获取值类型快照，不保存 TOC 指针、不发控制命令。独立优先级 1 任务每 200 ms 采样，取锁最多 10 ms，I²C 完全在锁外；每笔事务最多等待 50 ms，只更新变化的画面。初始化／通信失败后有界灭屏、清理并退出，不使音频停止、不循环重试。总线断开可能无法清除旧画面，日志明确禁用直到重启。

启动和目录失效显示 NO MEDIA／TRACK --；有效目录显示实际轨号与核心状态。软件时钟固定显示 NO AUDIO；I²S 文字仅表示输出模式。SH1106 初始化／分页与失败退出有主机侧测试，真实供电、字形方向、断屏运行及音频并行稳定性需要实屏验收。接线、配置与验收见 [显示说明](../oled-display.md)。
