# ADR-0026：正面大圆孔与内凹护网

- 日期：2026-11-09
- 依据：用户参考图要求正面先有标准大圆孔，护网略低于面板。
- 状态：CAD 实现；实物打印、支撑清理、强度与声学效果未验收。

前表面 Y=0 保留完整 Ø130 圆形孔口，中心 X=0、Z=76；护网正面位于 Y=2.5，形成 2.5 mm 的内凹层次。按用户最新要求采用“大于圆孔的护网衬在下面”的构造：护网底片 Ø136，每侧在面板下方延伸 3 mm；连接环外径 Ø136.5、内径 Ø135.8，完全隐藏在面板材料内。孔 Ø1.88、孔距 2.9，保持原来的规则错列孔阵。

本版替代先前的完整孔边界及 1.106 mm 连续实心边。底片源件有 1627 个完整孔，融合面板后，圆口内呈现 1531 个完整孔、92 个被圆边部分遮住的孔，另 4 孔完全藏在面板下。孔纹越过可见圆口边界，由圆孔自然截出可见范围；不为保留完整圆孔而在可见范围中留下无孔装饰环。

底片与面板仍融合为 P1 单一实体，没有新增可拆网片或紧固件。最终前壳逐孔检查孔壁深度和曲面面积，确认边缘为真实部分开孔，并保留 Y=0…2.5 的完整圆形孔壁。孔间最小筋宽仍为 1.02 mm；圆边附近的局部形状及支撑清理须用实物样件确认。

用户进一步确认将内凹由 1 mm 加深到 2.5 mm，增强面板与护网的层次感。原护网背面与 P3 前障板在 Y=5 名义接触，整片后移会侵入支架。因此仅将护网正面降低 2.5 mm，背面仍为 Y=5，局部厚度由 5 改为 2.5 mm。前壳其它竖直面、斜面及提手仍为 5 mm；喇叭前包络 Y=8，至护网背面名义间距仍为 3 mm。喇叭活动空间和安装基准仍需实物确认。

保留 P1 一体前壳／提手／护网、P2 后壳、P3 支架的三主体结构及 11 件刚性 PLA 零件。中心 X=0 的圆孔和孔阵保持左右对称，按钮等既有操控例外不变。

保存后读回检查记录在 `hardware/enclosure/validation.json` 的 `recessed_grille`：核对实际前壳完整圆边、圆口前 2.5 mm 无材料、护网厚度与背面坐标，并检查成品干涉和左右镜像。`grille-change-checks.json` 对比修改前保存模型，核对只有前壳成品变化。网格、拆装检查、预览和图册与当前模型同步。

前壳正面朝下打印时，护网距离底板 2.5 mm，须验证支撑接触面、去除力和细孔清理，不能沿用齐平护网的首层经验。切片完成不能代替打印或声学验收。
