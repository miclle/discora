# ADR-0045：P2 圆角梯形外口与连续内斜面

日期：2026-11-14。状态：已实现，CAD、拆装路径和切片检查通过；完整件打印及声学待实测。

> 后续配套：[ADR-0046](0046-p3-terminal-mouth.md) 只调整 P3 最后 4 mm 的渐扩口及一体口沿，P2 本体、打印文件与本页 P2 支撑设置保持。本页关于 P3 不变的比较结论属于 ADR-0045 阶段。

用户授权采用圆角梯形外口，使侧口与箱体斜线呼应，并减少上一版外圆角矩形与内五边形叠加的突兀感。本版只改变 P2 出口及其支撑设置；P3 整体、安装座、盲孔、出线孔和独立转弯导管保持 ADR-0043。

## 造型与接口

- 左右沿 X=0 镜像，外口齐平于 X=±85，不加外凸圈、格栅、饰片或连接筋。
- 实际外口包络约 **38.48 mm（Y）×28.20 mm（Z）**，圆角 **R5.6**；范围 Y=25.622–64.100、Z=50.900–79.100，Z 中心仍为 65 mm。
- 内口以 YZ 平面的四个理论尖角 `(24.75,52.5)`、`(62.5,52.5)`、`(62.5,77.5)`、`(37.25,77.5)` 定义梯形，再作 R4 圆角。外口是内口向外等距偏移 1.6 mm；在 4.85 mm 壁深内连续收至内口，余下 0.15 mm 为直口。
- 内外均为同一梯形轮廓，去掉 P2 壁内原有五边形折转。P2 内口约 **769.99 mm²**、外口约 **949.54 mm²**，11 个壁厚位置的面积向外单调增加。P3 净截面仍为 400 mm²，连同原 1 mm 轮廓余量形成的 482.11 mm² 投影均无遮挡。
- P2/P3 最近滑动间隙仍为 **0.7 mm**。P2 仍是导管之后的开放壳壁，不作为 P3 导管密封壁，也未新增拆卸步骤。装上 P3 后仍可能从某些角度看到内部斜顶导管；本版消除的是 P2 自身的两套轮廓。

## 打印取舍

第一版较小前缘倾角出现连续承接不足，故将前缘在 25 mm 高度内的 Y 偏移增至 12.5 mm，同时将外口展开量增至 1.6 mm。最终只在两侧前缘圆角收口处需要局部支撑。为保留圆角造型，本版接受开放区域可接近的树支撑，没有把该区域改成尖角。

**P2 关闭“仅关键区域支撑”和“仅在打印板生成支撑”**，其余仍为自动树支撑、30°、顶部间隙 0.20 mm。关闭“仅关键区域”也会增加原后壳开放结构的支撑，不能描述为仅添加了两个小支点。P3 继续使用原 3MF，两项设置都保持开启，声腔和导管内无新增支撑。

## 验证

证据：[梯形出口检查](../../hardware/enclosure/p2-trapezoid-outlet-checks.json)、[整机检查](../../hardware/enclosure/validation.json)、[七条拆装路径](../../hardware/enclosure/assembly-paths.json)。

- 保存并重读的 P2 是有效单实体，STL 闭合；左右镜像差集为零，出口邻域以外几何保持。P3 整体及所有未修改零件与 ADR-0044 基线的实体差集为零。保存后壳与构造源在出口区域一致。
- 11 个 0.002 mm 厚薄片与完整贯通投影均确认名义内口无侵入；整机静态碰撞、安装面保持及七条拆装路径检查通过。
- 全部 **440 层**与 ADR-0044 比较：出口之外没有新增显著悬挑，无新增无承接孤岛。出口圆角第 **329–337 层（65.8–67.4 mm）**有 20 个超过 0.05 mm² 的新增悬挑片段；检查下方支撑后，最大剩余未覆盖面积约 **0.01991 mm²**，低于既有 0.05 mm² 判据。相邻层增长包络仍为 0.35 mm。
- 出口第 330、333–335 层的 18 段超过 1 mm、没有下层模型承接的走线，在支撑覆盖检查中均被覆盖。它们属于本次 P2 圆角收口，**不是历史 18 处 P3 悬空问题**。P3 未变，其全层证据沿用 ADR-0043。
- 保存 3MF 的区域告警为空；包内 G-code 与审核文件相同。Bambu Studio 2.9.1.70、P2S 0.4 mm、Generic PLA、0.20 mm，预计 **9h 12m／286.84 g**。
- GUI 重新打开并切片，核对第 322、335 层的内侧及侧面视图；侧口树支撑可从开放侧口和后壳正面接近。GUI 本次重新切片显示约 **9h 9m／286.60 g**，与保存 CLI 切片有小幅差异；没有以 GUI 结果覆盖已审计文件。最后停在“准备”页左侧外观视图，未发送打印。

上述覆盖是按实际走线及既有邻层包络作的软件检查，不等于打印表面、支撑拆除力或声学已验证。现有整机图册尚未重绘本版开口。

```sh
python hardware/enclosure/check-rounded-outlet.py --profile trapezoid \
  --model hardware/enclosure/Discora.FCStd \
  --baseline tmp/cad-p2-trapezoid-outlet/baseline.FCStd \
  --output tmp/cad-p2-trapezoid-outlet/geometry-checks.json
```
