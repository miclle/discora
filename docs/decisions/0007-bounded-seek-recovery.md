# ADR-0007：可选的寻道间隔与单次读取恢复

- 日期：2026-11-01
- 状态：Accepted；实验结果单独记录，不作为默认策略启用
- 扩展 [ADR-0004](0004-bounded-cdda-probe.md) 和 [ADR-0005](0005-stream-and-buffer-bench.md)；下面的 opt-in 例外替代实验配置中“任何命令失败都不重放”的限制，默认及 USB 传输故障策略保持不变。

## 假设

远距离 READ CD 失败后已取得有效 `03/02/00`（NO SEEK COMPLETE）。先观察降低命令节奏是否减少失败，再观察设备仍连接且重新就绪时，一次同位置读取是否可恢复。设备曾在返回有效 sense 后约 450 ms 离线，因此等待时必须继续处理 USB 事件，不能盲目重发。

## 决策

1. `DISCORA_CDDA_SEEK_WAIT_MS` 默认 0，范围 0–3000 ms。仅在 12 位置寻道实验的每个新位置之前等待；两次重复读取之间不加间隔。等待期间处理 USB 事件，发现断连或 fault 就退出。它是 READ CD **之前的空闲间隔**，不发送 SEEK，也不能证明机械寻道已经完成。
2. `DISCORA_CDDA_SEEK_RECOVERY` 默认关闭；独立于寻道间隔，仅用于显式开启的 CD-DA 实验。它适用于短探测、寻道、整轨及缓冲的 READ CD，共享每次 MCU 启动最多一次的预算，不是每个位置一次。
3. 只有 READ CD 返回有效失败 CSW、REQUEST SENSE 成功解析为精确 `03/02/00`、目录仍有效、设备未断连或 fault、transfer 已归还时才预留预算。无 sense、其它错误或 USB transport error 都不进入此恢复。
4. 先消耗预算，再等待 1000 ms 并处理事件。设备状态异常即中止；否则仅发一次 TEST UNIT READY，成功才重放相同音轨、LBA、扇区数的 READ CD。TUR 失败即令目录失效并停止，不循环等待就绪；介质变化不按旧目录重放。
5. 重放只有完整长度且 CSW 成功才作为 recovered read 继续。重放失败保留日志并停止；必要时仅取一次 sense，不递归恢复。设备重连、重新取得目录都不重置恢复预算或整轮实验次数。
6. 保留首次失败日志、累计读取失败数（含重放失败）、预算预留数、恢复成功数和原始错误。`extended bench complete` 只说明工作负载完成，必须结合 `read outcome` 区分无失败通过和恢复后完成。缓冲阶段仍按真实消费时钟判定欠载，不因恢复而隐藏缺口。
7. 寻道日志分别记录等待量及读取耗时；读取计时不包含预先空闲的 1 秒，包含在读取调用内发生的恢复等待。比较性能时不得把等待成本忽略后称为端到端延迟降低。

## 验证边界

主机测试覆盖有效 sense、无效/缺失 sense、错误类别、已用预算和不健康连接的准入判断；不能代替 USB 断连时序或实际恢复验收。默认、仅等待、等待加恢复、无等待恢复对照分别构建。实际工作负载与默认恢复状态见 [实验记录](../records/2026-11-01-m2-seek-recovery.md)。未触发恢复分支的成功运行不能证明重放可用。

## 0.5.3：有界多轮复现

允许显式选择 1–20 轮相同 12 位置工作负载，默认仍为 1；独立 seek-only 开关可跳过整轨和缓冲。每位置两次读取，先记录 round / step / LBA，再执行，便于定位失败位置和第一次/重复读取。每个位置前检查从寻道阶段开始计时的 600 秒软截止，当前命令仍按原有期限结束；超限记为未完成并停止。恢复预算仍是整个 MCU 启动最多一次，任何无法恢复的错误立即结束，不因下一轮或设备重连重新授权。

0.5.4 为固定位置全部通过后的对照增加可选的确定性偏移变化：首轮不变，之后逐轮加 997 扇区并对合法起点范围取模。跨度至少为 8，使用 64 位中间值，READ CD 原有轨道边界检查仍执行。该开关不改变恢复准入、预算和截止，不把不同 LBA 的摘要差异判成错误；每个实际位置仍连续读两次核对。扩展取样范围不等于缓存旁路或冷启动验收。

## 0.5.5：真实与离线共用恢复编排

恢复顺序提取到平台无关函数，USB 仍提供同步的健康检查、事件等待、TUR 和相同请求重放回调。TUR 成功后再次检查健康状态，避免检查期间发现失联后继续重放。预算先消耗、不退款、不递归的语义不变。脚本化回调只用于离线控制流验证，不能声称实际光驱恢复成功；见 [验证记录](../records/2026-11-01-m2-recovery-flow.md)。
