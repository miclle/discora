# ADR-0017：PSRAM 音频队列与可选欠载恢复

日期：2026-11-07。状态：implemented；实机证据见[记录](../records/2026-11-07-buffered-playback.md)。本决策补充 ADR-0008/0009 的欠载处理，默认配置仍保持原行为。

## 背景

接 DAC 的旧候选使用 64 扇区内部 RAM（约 0.85 秒），持续播放约 35 分钟后在轨 9 欠载，待处理读取随后成功返回；续播轨 9 又出现同类停播。没有该次精确读取耗时，因此不能把延迟根因认定为光驱机械、供电或 USB 调度。

## 决策

1. 显式 PSRAM profile 分配 2 MiB 软件 PCM 环形队列，3 秒预填。USB 与 I²S DMA 保留内部 RAM，分配失败不降级。默认内部队列保留，兼容无 PSRAM 板。
2. 自动恢复由独立开关控制。欠载保留数据与源位置，输出 owner 关闭 I²S 后重缓冲；新数据达到门槛或已知 EOF 时自动继续。暂停、停止、换轨及真实失败阻止恢复，重连和上电不自动播放。
3. 记录完成读取的累计／最近／最大／平均耗时、慢读取次数及对应 LBA，状态查询汇总输出。统计包含 read_audio 内部恢复等待；不把尚未返回的请求当作已完成，也不逐请求打日志。
4. bench profile 固定当前 GPIO15/16/7 和 25% 双声道独立增益，关闭与 DIN 冲突的退盘键及其余未接控制。测试用供数暂停显式开启，正常构建关闭。

## 后果与验证边界

最多约 11.89 秒缓存可吸收部分抖动，不能处理无限等待或低于播放速率的持续输入。恢复期间会有静音间隔，关闭 DMA 可能丢弃其剩余数据；不称无缝播放。轨间关闭／预填策略保持不变。离线测试检查字节顺序、在途请求前后返回、重复欠载、控制取消、失败及 EOF 尾部；实机用明确标记的 15 秒供数暂停验证恢复，再用无注入配置正常连续播放。听感、长期稳定性与软件计数分开验收。
