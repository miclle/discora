# ADR-0008：CD-DA 生产者接入独立音频控制任务

- 日期：2026-11-01
- 状态：Accepted；软件时钟模式 bench-tested，I²S 适配器离线验证及构建，实机未验收

## 数据与任务所有权

USB client 仍是唯一 SCSI 命令生产者。播放器默认关闭，上电 stopped，目录发布不自动播放；与短探测/长时 bench 互斥。显式 UART 命令才允许连续 READ CD。每条读取仍为 1–8 扇区，不跨音轨，不增加 Data-Out 或机械控制命令。

`cd_player_core.c` 使用已有 `audio_core` 和 64 扇区 / 150528 字节内部 RAM 队列，48 扇区预填充；短轨预填门槛取轨长。首版只接受至少 8 扇区的双声道音频轨，拒绝数据轨/四声道轨，单轨结束即停止，不自动播放下一轨或循环。

USB 任务在互斥锁内领取值类型请求（音轨边界、LBA、扇区数、generation、serial），锁外执行 USB，然后在锁内检查代次并复制完整有效回复。共享 USB 回复不交给消费任务借用，也不使用 PSRAM DMA。一次只存在一个当前代次的 pending 请求；新代次不接收旧代次结果。

独立 output/control 任务拥有 UART 命令、输出适配器和私有输出块，独占 I²S 打开/写入/关闭。所有核心状态和队列操作由同一 mutex 保护，USB 等待和 I²S 阻塞写不持有该锁。输出任务可在 USB 长时等待时响应停止或换轨；已经发出的 USB 请求不强制取消，返回后按代次丢弃，不能把 pending=0 理解为 USB 已取消。

## 控制语义

- `play`：有效介质上从 stopped/pause/underrun 显式进入预填或播放；fault 须先 stop。EOF 后 play 从该轨起点重新开始。
- `pause`：关闭输出，保留软件队列和当前源位置；在途读取允许完成并入队，但不会继续派发读取或消费。
- `stop`：清空队列、改变代次、回到所选轨起点；旧回复无法推进当前位置。
- `track N` / `next` / `prev`：选择可用音频轨并开始预填；跳过不支持的轨，不绕回盘头。非法轨号或边界拒绝不清空队列、不改变代次、不关闭正在工作的输出。
- 源读取失败进入 fault；目录失效/断连清空旧数据，新目录发布仍为 stopped。每次启动一次的恢复预算仍由 USB context 持有，换轨不退款；播放器实验配置默认关闭该恢复。
- 消费量不足进入 underrun，不插入伪 PCM，也不自动重启；用户显式 play 才重缓冲。

## 两种输出适配

默认播放器配置使用软件时钟：每 10 ms 消费 441 个立体声帧，按实际时间追赶调度迟到，不把慢消费伪装为 1×。真实 CD 数据被消费后丢弃，不保存 PCM、不输出 GPIO/I²S、不产生声音。

I²S 配置使用原有 44.1 kHz / 16-bit / stereo Philips 适配器，候选 GPIO4/5/6；先预装 7056 字节，再按 1764 字节块提交，末尾按实际剩余帧截短。EOF 最后提交后预留 50 ms 供 DMA 排空再关闭；这只是软件策略，不是硬件排空测量。暂停/停止/换轨通过关闭并重建 I²S 丢弃旧 DMA，暂停可能丢弃最多约 40 ms 已提交数据，不承诺采样级无损暂停。`delivered` 只表示交给输出适配器，不等于已听到的帧数；没有独立 DMA 欠载计数。

## 验证

主机测试直接运行同一核心，验证跨批队列顺序、轨尾短批、EOF、暂停在途回复、停止/换轨代次、非法轨号、欠载显式恢复和介质失效。真实 CD 软件时钟模式另测 UART 控制、旧代次丢弃和持续速率；不得据此标为 DAC、I²S 时钟或模拟声道通过。实测与最终部署见 [记录](../records/2026-11-01-m3-cd-player.md)。

## 0.6.4 轨尾修正

已知源 EOF 时，暂停恢复不能继续等待无法达到的预填门槛。剩余非空队列直接恢复消费；重新创建 I²S 时，短尾帧可预装并以零补齐剩余 DMA 容量，只为收尾使用。补齐不属于 CD 数据，不参与摘要；普通欠载仍停止，不填静音继续假装播放。50 ms EOF 等待由适配器持有且不可重复延长，暂停/停止可直接关闭。该行为有共享代码离线证据，物理尾音完整性仍待 DAC 实测。

## 0.7.2 空载外设与日志调度

同步 UART 状态打印与 I²S 供数共用任务会占用 DMA 补充窗口。空载对照中，仅添加 UART 发送缓冲没有改善；将状态快照交给有界队列、由独立低优先级任务打印，并提高测试音供数优先级后，短序列事件溢出由 5 降至 0。最终不保留 UART TX 缓冲实验。队列满只累计丢报告，供数任务不等待日志。ISR 只累计完成/事件溢出，不输出日志，也不将回调数解释为有效 PCM 的精确播放位置。
