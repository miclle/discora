# ADR-0001：独立、低成本、ESP32-S3 优先

- 日期：2026-10-31
- 状态：Accepted

## 背景

希望让拆机光驱不依赖单板 Linux 电脑即可独立读取音乐 CD，并研究刻录能力。主板成本和体积是重要约束。首个试验对象为 MATSHITA DVD-R UJ-898。

## 决策

1. **独立项目 Discora**：不从任何既有多媒体/CD 机产品继承设计约束。
2. 以 **ESP32-S3 + ESP-IDF** 为首选 MCU 固件平台，不采用 Raspberry Pi 作为产品控制器。
3. **先播放后刻录**：M0–M3 优先形成 CD-DA + I²S 立体声端到端实验；M4 研究 CD-R/RW，不做预先保证。
4. 光驱通过 USB Host + 现有 SATA/USB 桥接器访问，而非直连 SATA。
5. 选择**可测、低成本、最小功能**方案，避免提前定制复杂 PCB。

## 理由和代价

- ESP32-S3 的原生 USB Full-Speed 理论带宽高于 CD-DA 1× 数据量；但仍须验证 USB 协议、缓冲、供电和桥接器行为。
- 刻录需要控制复杂 MMC 状态机，且受限于实际 USB 有效吞吐和最低允许写速，可能最终无法在此芯片上完成。
- 开发早期借助 Linux 预验证光驱是测试便利，不改变独立产品不使用 Linux 的目标。

## 重新评估条件

若证明桥接器不能透传必须的 MMC 命令，或实际 USB 带宽/供电无法稳定支持 CD-DA，暂停实施并形成新的 ADR，而不是忽视失败证据。
