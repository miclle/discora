# ADR-0005：完整音轨、寻道与软件时钟缓冲实验

- 日期：2026-10-31
- 状态：Accepted；实机结果另记
- 继承 [ADR-0004](0004-bounded-cdda-probe.md) 的只读白名单、30 秒音频数据截止和每次启动一次限制。

## 要验证的假设

短片段正确不保证长区间读取、寻道延迟或播放速率的缓冲稳定性。使用真实 READ CD 数据，分别观察机械寻道、持续 USB 读取和生产/消费数据完整性，不引入 DAC 反馈或模拟光驱数据。

## 实验边界

1. 新增默认关闭的 `CONFIG_DISCORA_CDDA_SOAK`，依赖短探测开关。先执行原短探测，仅其成功后继续扩展实验；任何失败结束当前阶段，不因重连自动重试。
2. 寻道阶段选择可用双声道音频轨中的首/末/中间轨，分别读轨内 +150 扇区、中央、末尾 8 扇区和起点，共 12 个位置。每个位置读 8 扇区两次，以 SHA-256 检查重复一致，记录首次读取耗时。它使用 READ CD 自带定位，不增加 SEEK 或其它命令。
3. 完整读取首条可用音轨，从 INDEX 01 起点到排他末地址，最多每次 8 扇区，最后一批按剩余长度截短。输出完整区间字节数、SHA-256、耗时、吞吐及最长读取；没有独立整轨参考时，不称为内容逐字节验收。
4. 缓冲阶段从首条可用音轨的 +150 扇区开始，按目录顺序跨轨，单条 READ CD 不跨越轨道边界。拒绝经过数据轨、四声道轨、不连续 LBA 或超出盘尾；不循环较短片段凑时长。
5. 默认消费时长 600 秒，可显式设为 60–1800 秒。64 扇区 / 150528 字节环形缓冲使用内部 DRAM，48 扇区 / 112896 字节预填充后才启动消费时钟。USB 接收缓冲仍由 Host 单独分配，不默认使用 PSRAM DMA。
6. 独立 FreeRTOS 任务每约 10 ms 根据实际单调时钟计算累计应消费量，按 176400 bytes/s、4 字节 stereo frame 对齐取走真实 PCM，随后丢弃。它是软件时钟消费端，不连接 I²S，也不模拟 DAC 或听感成功。记录任务最大调度迟到。
7. 生产/消费端分别计算按顺序流经的完整 bytes 的 SHA-256。完成必须同时满足目标字节数相同、完整消费、摘要相同、零欠载、消费任务已完成；空队列所需字节超过现存量即记录缺失量并结束，不自动补零、重缓冲或追认成功。
8. 环形缓冲的复制和元数据修改用短临界区保护；SHA 运算在临界区外进行。生产者在下次 USB read 前完成回复数据的复制/摘要；消费者先复制到私有块再计算摘要。结束或错误时等待消费任务确认停止，再释放缓冲；未确认时隔离内存至复位。
9. 长阶段关闭每条成功 READ CD 的日志，错误始终输出，每 10 秒输出进度。保留每阶段最长 read、缓冲有效低水位/高水位、欠载、缺失字节、跨轨次数及栈余量。低水位只统计生产尚未完成的期间，避免把最终正常排空当作欠载。

## 检查与证据

- 无设备测试：20,000 次随机入队/出队与独立递增帧序列核对，覆盖回绕、溢出、空读和帧对齐；游标检查跨轨拆分、盘尾、数据/四声道拒绝。
- 默认关闭与显式开启两种配置独立构建，保存源码、sdkconfig、产物和 UART 原始日志于 `.local/bench/`。
- [实测记录](../records/2026-10-31-m2-stream.md) 区分各阶段真实结果、软件消费模型和尚未测试的 I²S / 冷启动 / 故障恢复。
- 不打印、不保存或提交音乐 PCM；仅保留元数据和摘要。先前首次 USB 错误及电源隔离未确认的边界继续保留。

## 阶段隔离补充

首轮远距离寻道失败后，新增单独的寻道开关；第二轮回读 LBA 0 失败后，新增完整首轨开关。两项均关闭时，缓冲测试从短探测最后一个排他 LBA 顺序衔接，不回跳、不重复失败位置。日志记录各阶段 enabled / not_run，顺序缓冲成功不会覆盖寻道和整轨失败。失败 CSW 始终记录，即使普通成功 READ CD 日志被关闭。

## 欠载负向控制及退出保护补充

0.4.3 增加默认关闭的生产者暂停注入，必须关闭寻道及完整首轨阶段；用真实队列不足触发欠载，单独报告 negative-control 结果。若消费端两秒内未确认退出，直接保留隔离内存并返回，不读取仍可能变化的统计/摘要。正常流 600 秒通过、负向预期失败和非预期设备离线分开记录，见 [本轮记录](../records/2026-10-31-m2-underrun.md)。

## 2026-11-01：只读恢复实验的有限例外

0.5.2 新增默认关闭的单次 READ CD 恢复，仅接受有效 `03/02/00` 且设备仍连接、再次 TUR 就绪；传输错误不重放，重连不重置预算。此前无自动重放规则仍适用于默认配置，完整条件见 [ADR-0007](0007-bounded-seek-recovery.md)。
