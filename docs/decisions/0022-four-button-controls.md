# ADR-0022：四键播放控制与连续换轨

- 日期：2026-11-08
- 状态：Accepted；implemented，验收分层见[记录](../records/2026-11-08-buttons-row.md)
- 更新 ADR-0008／0009／0010／0011 的相关控制语义和有声引脚，不改写历史实验结论。

保留已调通的 GPIO15／16／7 音频接线；四键有声 profile 使用 GPIO1 播放／暂停、GPIO41 退碟、GPIO2 上一曲、GPIO42 下一曲，均常开接地、内部上拉。退碟引脚配置化；默认查询的 GPIO7 保留兼容，但有声四键明确覆盖为 GPIO41。播放键默认关闭，独立 overlay 开启，不改变历史 profile 的默认按键引脚。编译拒绝外设及按键引脚冲突。

播放／暂停与换轨由原输出 owner 处理，无新任务；扩展已有按键手势核心，任意两个以上播放／换轨键重叠后要求三个均稳定释放。退碟保留独立任务、单槽请求、USB client 唯一机械控制权和输出关闭确认。所有键采用 30 ms 消抖、长按单次、上电先释放；介质失效／fault 不积压播放动作。

新增核心 `cd_player_toggle` 和串口 `toggle`：停止从当前曲起点开始连续播放；播放、预填、欠载／重缓冲时暂停；暂停从保留位置恢复。连续轨尾排空的 stopped 是序列活动状态，toggle 应暂停跨曲，不能重播曲首。fault 不隐式恢复。

`next`／`prev` 与实体键统一：选定相邻受支持音轨并开启连续模式，暂停中保持暂停，其余可用状态开始预填；0.12.3 起手动首尾循环选曲，只有一条可播放音轨时不重启该曲（取代初版首尾拒绝规则）。诊断入口 `track N` 保留单轨语义，`play` 保留原开始／恢复语义；`stop`、`track N`、fault、介质失效取消连续模式。手动换轨不再取消连续模式，是对 ADR-0009／0011 的明确变更。

继续以 generation 隔离换轨后的旧队列和在途 USB 回复。暂停保留软件队列，已发 USB 请求可完成；音频 DMA 的约 40 ms 丢弃边界保持不变，不宣称无损暂停、无缝换轨或即时退碟。无盘／重插盘不上电自动播放，单次恢复预算不因按键退款。

接线、可复现构建、状态表及实机验收见[四键控制](../playback-controls.md)。

## 0.12.1：连续排针修订

用户要求四个按钮引脚相邻，采用元件面天线向上时右排 J2-4～7：GPIO1 播放／暂停、GPIO2 上一曲、GPIO42 下一曲、GPIO41 退碟。上一曲／下一曲 GPIO 配置化，旧默认 GPIO8／9 保留；四键 overlay 显式覆盖。GPIO41／42 不与外部 JTAG 共用，普通输入由 GPIO 驱动配置，不更改 eFuse。保留音频 GPIO15／16／7、OLED GPIO10／11 和 COM GPIO43／44。

洞洞板候选沿原 J2 排母焊脚引出（M／N／O／P，A），地线来自（J，A），经板外 P3 五芯接头连接前面板。没有新增占板插座或更改 CAD 包络；机内走线和接头固定仍需实物验收。旧 0.12.0 产物与日志作为历史保留，新证据见[引脚修订记录](../records/2026-11-08-buttons-row.md)。

## 0.12.3：盘尾复位与手动循环选曲

用户确认连续播放自然结束后选回首条可播放音轨并停止，再按播放从盘首开始；手动下一曲／上一曲则分别在末／首边界循环，暂停时保持暂停。自动序列不循环重播。只有一条可播放音轨时换轨为无动作。过滤规则仍跳过数据轨、四声道和不足 8 扇区的轨。

复位发生在输出 owner 排空并关闭适配器、完成可选 EOF 校验之后；保留此前 EOF／关闭输出日志，在完成事件中记录末曲代次、LBA 与提交给输出适配器前的软件消费字节数，然后将选择与缓冲游标复位。手动停止、诊断单曲 EOF、故障和失联不触发盘尾复位。软件验证及部署边界见[记录](../records/2026-11-08-disc-rewind.md)。
