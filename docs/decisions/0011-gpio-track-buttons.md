# ADR-0011：实体换轨键复用播放器控制

> 2026-11-08：四键有声引脚及 next／prev／toggle 语义由 [ADR-0022](0022-four-button-controls.md) 更新；下文保留当时决策与实验边界。

- 日期：2026-11-01
- 状态：Accepted；implemented，硬件未验收
- 补充 [ADR-0008](0008-cd-player-control.md) 和 [ADR-0010](0010-gpio-eject-button.md)

GPIO8 为上一曲，GPIO9 为下一曲，均为内部上拉、常开按键到 GND。依据仓库板卡资料选取 J1-12 / J1-15；与默认 GPIO4/5/6 音频、GPIO7 退盘不冲突，实物引脚仍须核实。固定引脚、可关闭功能，I²S 冲突在构建时拒绝。仅 CD 播放器模式默认启用，不改变默认查询模式或上电 stopped。

将原退盘消抖核心按原算法提取为 `button_core`，退盘保留独立任务与原子单槽请求；两个换轨键由输出 owner 直接轮询，无额外任务或 USB 命令入口。共享 30 ms 双向消抖、上电先释放及长按单次规则。检测双键后要求两键均稳定释放；介质不可用或 fault 时不保留动作，目录更换与失效在播放器锁内重置手势。

换轨采样及 `cd_player_step` 在同一播放器锁内执行，沿用串口 prev/next 的曲目筛选、首尾不循环、清队列、改变代次和取消连续模式。输出 owner 在成功选择后关闭旧 I²S；边界拒绝不关闭输出。失败关闭进入既有 fault 路径。USB client 仍唯一发送 READ CD，旧在途回复返回后按代次拒收。

不增加自动播放、循环、长按连跳、音轨内 seek 或新的 SCSI 策略。暂停／停止时换轨也从目标轨开头启动，与现有串口行为一致。查询模式不能仅凭按键启用播放器；真实输出与物理按键须单独验收。接线和验收见[操作说明](../track-buttons.md)，软件证据见[记录](../records/2026-11-01-track-buttons.md)。
