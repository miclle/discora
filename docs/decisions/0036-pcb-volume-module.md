# ADR-0036：带 PCB 插接头的 B50K 音量模块

- 日期：2026-11-14。
- 依据：用户选定带 PCB 的 B50K 模块，确认 PCB 35×26.2×1.5 mm，含引脚及插好插头的总厚度为 15 mm，轴长15／花轴长10；轴线沿板宽居中，板前边与电位器安装面实际齐平。
- 状态：CAD 已实现；验证范围与报告见下文。尚未实物打印、试装或电气验收。

## 安装方向与取舍

按照片中的结构，PCB 与旋转轴平行；35 为板宽，26.2 沿轴伸入机内，15 为垂直板面的完整厚度。沿用原安装面局部 Y=3.6、轴心 X=48、Y=18、Z≈177.789，PCB 前边从安装面起算，后边至局部 Y=29.8。不额外叠加插头厚度。

照片朝向的完整包络与主控元件预留 `MCUChip` 相交约 21.116 mm³；前壳原内槽也不能容纳新模块。将电位器和 PCB 绕轴转 90°，使 35 mm 板宽沿前斜面上下展开，局部包络改为 X=−6.5…8.5、Y=3.6…29.8、Z=−17.5…17.5。无需移动主控、显示、四键或旋钮轴心。完整包络至支架最小净距约5.896 mm、至主控元件9.805 mm、至后壳9 mm、至光驱26.992 mm。

前壳内侧避让槽覆盖完整包络，横向各留0.3 mm、后端留0.3 mm，局部尺寸 X/Y/Z=15.6/26.5/35.6，从 Y=3.6 起切除。原外侧 Ø24.8×1.6 凹位、Ø7.2 孔及2 mm螺母夹持面保留；凹位之外的内槽底厚3.6 mm，普通斜面仍厚5 mm。该槽属于既有操控布局的不对称例外，纳入精确操控切除体及镜像区域；没有放宽其余外壳、提手、格栅和声学结构的左右对称检查。

`VolumePot` 内分别保存电位器本体、PCB、后端插接预留、板底引脚预留四个不重叠实体；插头和引脚是矩形包络，不虚构插座型号、真实脚距或两个安装孔。检查另以完整实心包络填满所有空隙，不能靠简化零件间的空白规避干涉。

## 保留的名义值与实物边界

新模块主体外形、轴径、齿形、螺纹和螺母没有新增测量，沿用原 B50K 的9.5×14.5×11.2主体、2.7轴偏心、Ø5.8花轴、Ø6.8×5螺纹及9.8×1.9螺母。PCB示意贴靠原主体引脚面；该相对高度仍是名义安装假设。原10K特性表不转作新模块的开关额定值证明。

电位器和PCB转向不改变十字旋钮形状。装配时先锁紧螺母，再按实物关断止挡校准指示条并压入；支撑主体，插拔时托住PCB。扩大后的槽不再以紧贴旧主体侧面提供限转，防松和保持力依赖螺母夹紧及实际配合验证。

静态包络包含已插好的插头，不包括远端线束的走向、弯折和拔插行程。拆卸电位器须先将前壳整体向前取下，再拆旋钮及螺母，最后沿轴将模块退出。不能在机内直接向后拔模块：原位内移约6 mm开始与支架包络相交。专项退出检查以已拆下的前壳组件为参照，不把留在机身内的支架误算成前壳上的障碍。维护前先断电、释放线束；CAD检查不代表已完成板间电气接线或电源开关容量验证。
