# 三主体 PLA 打印与拆装检查

本次采用用户提供的拓竹 P2SC、256 × 256 × 256 mm 成型空间及 0.4 / 0.2 mm 喷嘴信息。**已做 0.4 mm 喷嘴的本地切片；尚未实际打印或装配。** 采用本机 Bambu Studio 的 P2S 配置，未连接打印机；0.2 mm 喷嘴仅记录为可用设备，未验证其切片。

模型与图纸见[外壳说明](../hardware/enclosure/README.md)和[唯一彩色图册](../hardware/enclosure/drawings/Discora-V4-drawing-book-color.pdf)。三个主体均为单一连续实体；含两侧孔、键帽、旋钮，共 7 件刚性 PLA 零件，软脚垫与透明窗片另计。

三主体各一盘，其余四件一盘。每个单件的闭合网格和 5 mm brim 边界均适合 256³ 空间，小件盘另经切片器自动排布。参考工艺：Generic PLA、0.4 mm 喷嘴、0.20 mm 层高、3 层壁、15% gyroid 填充、自动树状支撑（仅从底板生成）、30° 阈值、0.2 mm 顶部接触间隙、5 mm 外侧 brim。此配置用于可切片性检查，仍需结合耗材、平台和实际支撑清理结果调整。

## 装配顺序

1. 清理支撑、brim 和孔口，检查三个主体没有断筋、翘曲或薄壁破损；先用小样核对 0.3 mm 配合间隙和螺钉底孔。
2. 在 P2 装入电池和绑带、DAC；光驱沿两侧导轨从顶部放入。实际导线和板卡固定方式尚需按实物补全。
3. 在 P3 安装两只喇叭、功放、桥接器和主控；核对喇叭安装基准与密封材料后，从正面把总成推入后壳，固定四处前向连接。左右侧孔此时保持取下。
4. 从左右外侧插入两个侧孔件，各固定两处连接；连接线束，确认没有压线，保留前壳拆卸所需的可断开连接和维护余量。
5. P1 预装窗片、显示板和操控件，按“向后移至壳体上方、再下降 40 mm”的反向路径合拢，固定四处前壳连接。实际线束必须另行检查。

拆卸按相反顺序。先卸前壳四个螺钉、断开操控线，前壳上提 40 mm 后向前移出；拆 P3 前卸两侧孔、断线并卸支架四螺钉，再向前抽出。保守维护顺序为取出 P3 后再向上取光驱。电池断线并松绑后向前取出，几何检查允许保留 P3。上述位移是检查用脱离行程，不是所有动作都必须移动完整 140 / 150 / 180 mm。

连接孔见图册第 2 页：前壳和支架 Ø2.8 通孔配 Ø2.0 底孔；侧孔 Ø2.2 通孔配 Ø1.6 底孔。此处只是名义的螺杆、沉头和底孔预留，具体螺纹类型、螺钉长度、孔径补偿和扭矩未验收；不要把它当成已定型的紧固件 BOM。反复拆装寿命需试样；如后续改为嵌件，应另行增加足够安装柱体积并重新检查干涉。

## 检查范围

[assembly-paths.json](../hardware/enclosure/assembly-paths.json)记录以下条件和结果：

- P3 连同喇叭、功放、桥接器、主控向前：按各构造件的包围盒作连续保守扫掠；前壳、侧孔及紧固件已取下。
- 光驱向上：包围盒连续扫掠，与后壳、电池、DAC、脚垫比较；检查未把 P3 当作固定件，故采用先取 P3 的保守顺序。
- 电池向前：包围盒连续扫掠，含 P3 和光驱作为固定件；绑带、线缆取下。
- 两侧孔向外：沿 X 对朝前表面挤出，检查连续运动包络；螺钉取下。
- 前壳总成：真实 B-rep 先以 0.5 mm 步长向上到 40，再以 1 mm 步长向前，所有采样无碰撞；这不是连续运动的严格证明。

CAD 成品静态无干涉、网格闭合和切片成功，不代表喇叭安装孔已测、密封可靠、支撑必然容易拆除、PLA 提手承载足够或实物线材可装入。应先打印局部配合／护网／螺钉试片，再打印主体做装配样件；打印后核对提手层间受力、螺柱、喇叭振膜空间、温升与实际进退碟。电池标称尺寸不含已验证的线材和插头，外围电源模块也未完整建模。

## 重现

先运行外壳建模与静态检查，用可导入 FreeCAD、MeshPart 的 Python 导出七件 STL，再用普通 Python 调用本机切片器：

```bash
"$DISCORA_FREECAD_PYTHON" hardware/enclosure/check-assembly.py
"$DISCORA_FREECAD_PYTHON" hardware/enclosure/export-print-parts.py
python3 hardware/enclosure/slice-print-parts.py
```

切片器和配置目录可用 `--bambu`、`--profiles` 指定，临时网格目录可用 `--meshes` 指定。脚本核对模型与网格摘要、返回码及 G-code 统计；不会发起打印。
