# 三主体 PLA 打印与拆装检查

2026-11-08 随前壳背面锁紧连接的模型重新生成网格与四盘切片。

本次采用用户提供的拓竹 P2SC、256 × 256 × 256 mm 成型空间及 0.4 / 0.2 mm 喷嘴信息。**已做 0.4 mm 喷嘴的本地切片；尚未实际打印或装配。** 采用本机 Bambu Studio 的 P2S 配置，未连接打印机；0.2 mm 喷嘴仅记录为可用设备，未验证其切片。

模型与图纸见[外壳说明](../hardware/enclosure/README.md)和[唯一彩色图册](../hardware/enclosure/drawings/Discora-V4-drawing-book-color.pdf)。三个主体均为单一连续实体；含两侧孔、四键帽、压板和旋钮，共 11 件刚性 PLA 零件，软脚垫与透明窗片另计。

历史版曾抽查三主体在打印 Z≈0.2 / 2 / 6 / 20 / 50 mm 的挤出路径。本版已重新完成四盘切片，但没有把旧版逐层检查直接视为新分件的支撑清理验证；仍须核对后斜面内侧支撑的可接近性，并实测去除力与残留。切片摘要及 STL、配置、G-code 摘要记录在 [print-checks.json](../hardware/enclosure/print-checks.json)。安装的官方机型结束代码含 `T65535`，CLI 通用解析器会输出对应 `Invalid T command` 提示；四盘切片返回码均为 0。保留原厂代码，没有将该提示解释为硬件执行验证，也没有向机器发送 G-code。临时文件留在被忽略的 `tmp/`，仓库只保存可复现脚本与证据摘要。

下方两处背锁通道深 65.8 mm，需细长螺丝刀；上方两处位于后斜面，轴向深约 21.1 mm。螺钉头径应不超过 4 mm，实际批头与刀杆须核对。详见 [ADR-0024](decisions/0024-rear-access-front-cover-fasteners.md)。

## 装配顺序

1. 清理支撑、brim 和孔口，检查三个主体没有断筋、翘曲或薄壁破损；先用小样核对 0.3 mm 配合间隙和螺钉底孔。
2. 在 P2 装入电池和绑带、DAC；支架尚未装入时，光驱按下述拆卸路径反向从正面侧转装入两侧导轨。实际导线和板卡固定方式尚需按实物补全。
3. 在 P3 安装两只喇叭、功放、桥接器和主控；核对喇叭安装基准与密封材料后，从正面把总成推入后壳，固定四处前向连接。左右侧孔此时保持取下。
4. 从左右外侧插入两个侧孔件，各固定两处连接；连接线束，确认没有压线，保留前壳拆卸所需的可断开连接和维护余量。
5. P1 预装窗片、显示板和操控件；从内侧装入四个键帽、开关，固定可拆压板，确认回弹和引脚／焊点／线缆不受压后，向后合拢前壳，从后壁下方和后斜面四个深孔固定连接。实际线束必须另行检查。

拆卸按相反顺序。从背面深孔取出前壳四个螺钉、断开操控线，前壳向前移出；拆 P3 前卸两侧孔、断线并卸支架四螺钉，再向前抽出。光驱需先取出 P3：沿 −Y 前移 11.5 mm，再绕自身中心沿 Z 旋转 −30°并同步前移 15.75 mm，最后向前抽出。不能直接直线抽出或向上拔出光驱；安装采用反向路径。电池断线并松绑后向前取出，几何检查允许保留 P3。上述位移是检查用脱离行程，不是所有动作都必须移动完整 140 / 150 mm。

连接孔见图册第 2 页：前壳改为背面 Ø4.4 深孔内的 Ø2.2 通孔配 Ø1.6 盲底孔，名义 2×8 mm 螺钉、头径不超过 4；支架仍为 Ø2.8 通孔配 Ø2.0 底孔；侧孔 Ø2.2 通孔配 Ø1.6 底孔。此处只是名义的螺杆、沉头和底孔预留，具体螺纹类型、螺钉长度、孔径补偿和扭矩未验收；不要把它当成已定型的紧固件 BOM。反复拆装寿命需试样；如后续改为嵌件，应另行增加足够安装柱体积并重新检查干涉。

## 检查范围

[assembly-paths.json](../hardware/enclosure/assembly-paths.json)记录以下条件和结果：

- P3 连同喇叭、功放、桥接器、主控向前：按各构造件的包围盒作连续保守扫掠；前壳、侧孔及紧固件已取下。
- 光驱从前方侧转取出：初始 11.5 mm 平移和最终抽出采用连续保守包围盒扫掠；中间 −30° 转动与同步 15.75 mm 前移按 0.5° 步长检查 61 个真实 B-rep 姿态。与后壳、电池、DAC、脚垫比较；P3 预先取出。转动检查是离散采样，不是连续证明。
- 电池向前：包围盒连续扫掠，含 P3 和光驱作为固定件；绑带、线缆取下。
- 两侧孔向外：沿 X 对朝前表面挤出，检查连续运动包络；螺钉取下。
- 前壳总成：取出四个背面螺钉后，真实 B-rep 以 1 mm 步长向前退出，所有采样无碰撞；这不是连续运动的严格证明。

四键压板的 Ø4 中央支点基于本体背面有承压空间的假设；实物引脚排列尚未确认。引脚长度 3.7 按本体背面另计，距压板平面名义 0.8，不能直接当作焊点空间验收。按压头直径及开关行程仍待测，先验证局部按键样件。

CAD 成品静态无干涉、网格闭合和切片成功，不代表喇叭安装孔已测、密封可靠、支撑必然容易拆除、PLA 提手承载足够或实物线材可装入。应先打印局部配合／护网／螺钉试片，再打印主体做装配样件；打印后核对提手层间受力、螺柱、喇叭振膜空间、温升与实际进退碟。电池标称尺寸不含已验证的线材和插头，外围电源模块也未完整建模。

## 重现

先运行外壳建模与静态检查，用可导入 FreeCAD、MeshPart 的 Python 导出十一件 STL，再用普通 Python 调用本机切片器：

```bash
"$DISCORA_FREECAD_PYTHON" hardware/enclosure/check-fasteners.py
"$DISCORA_FREECAD_PYTHON" hardware/enclosure/check-buttons.py
"$DISCORA_FREECAD_PYTHON" hardware/enclosure/check-assembly.py
"$DISCORA_FREECAD_PYTHON" hardware/enclosure/export-print-parts.py
python3 hardware/enclosure/slice-print-parts.py
```

切片器和配置目录可用 `--bambu`、`--profiles` 指定，临时网格目录可用 `--meshes` 指定。脚本核对模型与网格摘要、返回码及 G-code 统计；不会发起打印。
