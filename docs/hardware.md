## 功放选型：TPA3118D2（短时试听通过）

2026-11-03，用户确认已有 TPA3118D2 和 TPA3116D2 两款功放板，并决定先选 **TPA3118D2** 用于 Discora。随后本板与 PCM5102A、双喇叭完成短时原始 CD 立体声试听，记为 `bench-tested`；完整功率、热与整机可靠性未验收，见[音频对照](records/2026-11-07-cybertrack-audio-crosscheck.md)。

- **选型理由**：当前 [V4 小型双喇叭布局](../hardware/enclosure/README.md)优先考虑安装空间、散热与实际聆听音量，尚无需要大功率持续输出的实测依据。优先验证现有 TPA3118D2；TPA3116D2 保留为较大外接音箱或后续实测需要更大输出时的备选。不能仅凭芯片型号断言成品板更小、底噪更低、更省电或音质更好。
- **商品标称**：标题中的“2 × 45 W”“DC24V”为用户提供的商品描述，卖家页面未能读取，未核实其负载、失真、散热或持续输出条件，不能作为实测功率或直接上电依据。
- **芯片规格参考**：[TI TPA3118D2 官方资料](https://www.ti.com/product/TPA3118D2)列出 24 V、8 Ω 下的 2 × 30 W 配置；具体条件与功率／失真曲线见 [TI 数据手册](https://www.ti.com/lit/ds/symlink/tpa3118d2.pdf)。这是芯片级资料，不证明本板可达到相同输出，也不替代板级供电和散热核对。
- **接入方案**：ESP32-S3 → I²S → PCM5102 / PCM5102A → 模拟 L/R → TPA3118D2 → 左右喇叭。该芯片为模拟输入 Class-D 功放，不能直接连接 I²S。功放使用足额电源支路，不从 ESP32 开发板取大电流；模拟输入信号地按实际板卡接线。BTL 喇叭输出的 L−、R− 不得互连或接 GND。

## USB 接线与电源注意

2026-11-05，用户选定 [5600mAh 成品电池包](../hardware/Battery-3S2P-5600mAh/README.md)，参数依据用户提供的商品图和报价，未独立核实在线 SKU。该包为三串锂电原始电压输出，不能当作恒定 12V 电源；Type-C 三串充电、12V 升降压模块尚未定型，边充边播未确认。2026-11-07 已选定两块 [DCE001 固定 5V 降压模块](../hardware/DCE001-5V/README.md)，分别供主控和光驱，接入为 planned；两路输出不得并联，USB VBUS 防回灌路径及光驱带载能力待确认，见 [ADR-0018](decisions/0018-dual-5v-buck.md)。用户已明确选择平排 112 × 70 × 20mm，V4 已适配其商品标称包络并重跑静态几何检查；线材、插头、固定方式及外围电源板仍未完成实物装配验证。机械取舍见 [ADR-0015](decisions/0015-flat-battery-enclosure.md)。取舍见 [ADR-0014](decisions/0014-5600mah-battery-pack.md)。

组装拓扑、UART0、Type-C Hub 角色和首次上电顺序见 [M1 组装说明](assembly.md)。用户已有 ESP32-S3、UJ-898、Type-C Hub 和电源；板卡、Hub、桥接器的具体型号与接线仍待确认。

- ESP32-S3 原生 USB OTG D− / D+ 常对应 GPIO19 / GPIO20；必须核对**具体开发板原理图**是否已经连接到板载 USB 接口。
- USB Host 需要向光驱/桥接器提供合规 **5V VBUS**。不能直接将 USB 光驱挂在 3.3V GPIO 或未经校验的开发板弱供电上。
- 使用独立供电、带电流余量的 USB 接口或供电 Hub 作为最初的实验路径；保持 USB 数据连接与公共地正确。
- 上电、吸盘、加速旋转和读盘过程中测量 5V 是否跌落，监控 ESP32-S3 brownout/reboot。
- 确认桥接器在 Full-Speed 模式下可枚举；检查接口是 BOT (0x50) 还是不受首版支持的 UAS (0x62)。
- 原生 USB PHY 用于 Host 时，日志走 UART0；如板上没有独立 USB-UART，需要 3.3V 逻辑的外接转接器。PD 供电口不等于 Host 数据口。
- 音频 L/R 从 DAC 输出；需要驱动 4Ω/8Ω 无源喇叭时增加双声道功放。
- 光驱电机供电、模拟音频接地布线和功放电源噪声应分别评估。

## USB 故障与后续对照

移除 Hub 后仍曾发生寻道失败；后续既有整盘成功，也有 DATA STALL／03/02/00、CSW 超时和根端口断连，不能合并归因。最新一次真实有界恢复成功与限制见[STALL 诊断](records/2026-11-09-usb-stall-diagnostic.md)，下一步按[路线图](roadmap.md)逐项比较介质、负载供电及数据连接。现有数据不支持直接认定更换某一硬件就能修复。

## 音频与按键接线

台架使用 GPIO15→BCK、GPIO16→LCK、GPIO7→DIN，PCM5102A 模块 SCK 接 GND，DAC 模拟 L／GND／R 接功放，已完成短时立体声试听。仓库默认 GPIO4／5／6 与该台架 profile 不同，配置和模块核对见[音频输出](audio-output.md)，不照默认构建推断当前实物接线。

四键方案使用 GPIO1 播放／暂停、GPIO2 上一曲、GPIO42 下一曲、GPIO41 退碟，常开接 GND。GPIO7 保留给 DAC DIN，禁止混用旧 GPIO7 退盘接法。当前基本操作已获用户确认；接线、J2 排针位置、profile 与剩余专项验收统一见[四键控制](playback-controls.md)。
