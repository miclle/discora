## USB 接线与电源注意

组装拓扑、UART0、Type-C Hub 角色和首次上电顺序见 [M1 组装说明](assembly.md)。用户已有 ESP32-S3、UJ-898、Type-C Hub 和电源；板卡、Hub、桥接器的具体型号与接线仍待确认。

- ESP32-S3 原生 USB OTG D− / D+ 常对应 GPIO19 / GPIO20；必须核对**具体开发板原理图**是否已经连接到板载 USB 接口。
- USB Host 需要向光驱/桥接器提供合规 **5V VBUS**。不能直接将 USB 光驱挂在 3.3V GPIO 或未经校验的开发板弱供电上。
- 使用独立供电、带电流余量的 USB 接口或供电 Hub 作为最初的实验路径；保持 USB 数据连接与公共地正确。
- 上电、吸盘、加速旋转和读盘过程中测量 5V 是否跌落，监控 ESP32-S3 brownout/reboot。
- 确认桥接器在 Full-Speed 模式下可枚举；检查接口是 BOT (0x50) 还是不受首版支持的 UAS (0x62)。
- 原生 USB PHY 用于 Host 时，日志走 UART0；如板上没有独立 USB-UART，需要 3.3V 逻辑的外接转接器。PD 供电口不等于 Host 数据口。
- 音频 L/R 从 DAC 输出；需要驱动 4Ω/8Ω 无源喇叭时增加双声道功放。
- 光驱电机供电、模拟音频接地布线和功放电源噪声应分别评估。

## 成本目标

目标是相比 Linux SBC 显著降低控制器成本，但**不预先承诺具体人民币 BOM 金额**。明确记录 MCU、USB 供电、DAC、功放、接口、PCB 及光驱成本；已拥有的零件仍应标明重置成本。

## 寻道故障的下一项对照设备

2026-10-31 已完成本盘的 600 秒顺序读取 / 软件缓冲，但远距离寻道和回读 LBA 0 失败；电脑对应位置可读。2026-11-01 已用新 USB-C 公头 → USB-A 母口 OTG 移除 Hub 直连。首次就绪前反复离线；同一 OTG 接电脑后取得目录和匹配参考的三段数据，保持辅助供电接回 MCU 后基础查询及短顺序读取成功，但末轨 LBA 223917 仍返回命令失败，随后 sense 超时。本轮没有 USB 断连，移除 Hub 没有解决该寻道故障。已恢复默认关闭读取实验的固件，下一步诊断错误返回；带载供电和根因未确认，暂不据此要求更换光驱或主控。详见 [首次对照](records/2026-11-01-m2-otg-direct.md) 和 [后续直连实测](records/2026-11-01-m2-otg-after-pc.md)。

## 音频模块到货前的软件准备

已实现独立测试音诊断，候选 GPIO4 / GPIO5 / GPIO6 为 BCLK / LRCK / DATA，避开 native USB、COM 和内存引脚。该引脚方案及模块 VIN、SCK / FMT / XSMT 接法未实测；以到货实物确认电源和跳线。详见 [音频接线与验收草案](audio-output.md)。仅代码和构建完成，不把其它板卡历史测试当作本项目 DAC 验收。

## 退盘按键

选用常开非自锁轻触按键，接 GPIO7 与 GND；GPIO 内部上拉、30 ms 软件消抖。供应商图纸 GPIO7 为 J1-7，未占用当前 I²S/USB/UART/PSRAM。固件查询与播放器配置默认启用，用户已确认默认查询配置的基本按键退盘成功；板卡逐网、电气及其余场景仍待验收，见[接线说明](eject-button.md)。

## 上一曲／下一曲按键

播放器模式新增两个常开非自锁按键，分别接 GPIO8／GPIO9 与 GND，内部上拉。供应商资料位置为 J1-12／J1-15，与默认音频和 GPIO7 退盘分开；实物逐网与按键换轨未验收，当前已部署支持三键的软件时钟播放器。详见[接线和配置](track-buttons.md)。
